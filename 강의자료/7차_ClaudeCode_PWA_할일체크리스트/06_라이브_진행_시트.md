> 강의 중 **위에서부터 순서대로** 회색 박스를 복사해 Claude Code에 붙여넣으면 됩니다.
> ⚠️ 박스 하나 = 한 번 보내기(붙여넣고 Enter). 여러 개면 하나씩, 끝나길 기다렸다 다음.
> 프롬프트만 → `06_프롬프트만.txt`

> ✍️ **이번 강의 방식**: 빈손에서 만들지 않습니다. **잘 짜인 PWA를 받아** → 구조를 읽고 → 내 입맛대로 개조하고 → 배포·설치.

## 📖 용어 한 줄 (강사 치트시트)
| 용어 | 설명 |
|---|---|
| **PWA** | 웹인데 폰에 설치·오프라인 되는 앱 |
| **레이어** | 파일을 역할별로 나눈 겹 — 데이터(store)·동작(actions)·화면(render)·연결(app) |
| **순수 함수** | 입력만 받아 출력만 내는 함수(저장·화면 안 건드림). actions가 그것 |
| **매니페스트(manifest.json)** | 앱 이름·아이콘·테마색(홈 화면 아이콘) |
| **서비스워커(sw.js)** | 앱 파일 캐시 → 인터넷 없이 열림. 코드 바꾸면 캐시 버전 올리기 |
| **localStorage** | 데이터를 폰에 남기는 저장소(store.js) |
| **HTTPS / Vercel** | 자물쇠 주소(설치·오프라인 필수) / 무료 배포처 |

## 0단계 · 받은 앱 실행하기
```
이 폴더에 있는 할 일 앱을 로컬 서버로 띄워줘. 브라우저에서 어떤 주소로 열면 되는지 알려줘.
```
✅ `localhost` 주소 → 열어서 할 일 추가·체크·삭제 동작 확인. "이미 작동하죠? 이제 뜯어봅니다." (모바일 뷰로 폰처럼)

## 1단계 · 구조 투어 (읽고 이해하기) ⭐
📚 **레이어**: 데이터(store)·동작(actions)·화면(render)·연결(app) — 한 파일 = 한 책임.
```
이 폴더의 구조와 각 파일(store.js, actions.js, render.js, app.js)이 무슨 일을 하는지, 그리고 사용자가 할 일을 추가하면 데이터가 어떻게 흐르는지, 코딩 처음 하는 사람도 알게 쉽게 설명해줘.
```
```
@actions.js 이 파일이 무슨 일을 하는지, 입력과 출력이 뭔지 한 줄로 설명해줘.
```
✅ "actions는 (목록, 입력) → 새 목록만 계산한다 / store는 저장 / render는 화면" — **고칠 곳의 지도**를 얻음.
💡 강사 멘트: "한 파일이 한 가지만 하니까, 뭘 고칠 때 어디 건드릴지 바로 보이죠."

## 2단계 · 디자인 개조 (성공 경험)
```
앱 이름을 '오늘 할 일'로 바꿔줘. 화면 위 제목과 manifest.json의 이름 둘 다.
```
```
테마색을 보라에서 청록(#0ea5a4)으로 바꿔줘. styles.css랑 manifest.json, 그리고 index.html의 theme-color까지 일관되게.
```
✅ 새로고침해 바로 확인. "벌써 내 앱 같죠?" (색·이름은 본인 취향대로 자유롭게)
⚠️ 고친 게 안 보이면 → 5단계(캐시) 참고. 개발 중엔 그냥 새로고침으로도 보통 보임.

## 3단계 · 내 이미지로 아이콘 (← 경로를 내 것으로)
👉 아이콘용 이미지 1장(정사각형) 준비 — 파일을 Git Bash 창에 끌어다 놓으면 경로가 찍힘.
```
앱 아이콘으로 쓸 이미지를 준비했어. 경로는 C:\Users\내이름\Desktop\my-icon.png 야. 이 이미지를 가져와 192×192, 512×512 PNG 아이콘으로 만들어 icons 폴더에 넣고, manifest.json과 index.html(apple-touch-icon)에 연결해줘.
```
✅ 내 이미지가 홈 화면 아이콘이 됨. (개발자도구 Application → Manifest에서 확인)

## 4단계 · 기능 개조 ⭐ ('내 앱'다워짐)
🧩 핵심: **"어느 레이어를 고치는지"**를 같이 말한다 → 구조 이해 + 정확한 결과. (아래 중 하나 택1, 더 해도 됨)
```
각 할 일에 '중요(별표)' 표시를 켜고 끄는 기능을 추가해줘. actions.js에 순수 함수로 toggleImportant를 만들고, app.js에서 연결하고, render.js에서 별표를 보여줘. 중요한 건 목록 위로 정렬해줘.
```
```
(대안) 맨 위에 '오늘 3/5 완료(60%)' 같은 진행률을 보여줘. render에서 계산해서 표시해줘.
```
```
(대안) '완료한 것 숨기기' 토글 버튼을 추가해줘.
```
✅ 기능이 붙음. "구조가 좋아서 어디 고칠지 바로 나오죠?"
⚠️ 꼬이면: "actions부터 함수 만들고, 그다음 render에 표시하는 순서로 다시 해줘."
