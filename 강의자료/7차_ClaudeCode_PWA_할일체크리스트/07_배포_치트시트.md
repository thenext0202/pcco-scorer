# 7차 배포 치트시트 — Claude Code로 Vercel 배포

> 강의의 클라이맥스(배포→폰 설치)에서 안 막히게. **Claude Code에 붙여넣어 진행**하는 방식이 메인입니다.
> ⚠️ 박스 하나 = 한 번 보내기(붙여넣고 Enter). 끝나길 기다렸다 다음.

## 📚 용어 (강사용)
- **Vercel** — 무료로 웹앱을 인터넷에 올려 **HTTPS 주소**를 주는 곳. (PWA 설치·오프라인은 HTTPS에서만 됨)
- **CLI** — 명령으로 쓰는 도구. Claude Code가 대신 실행해 줍니다.
- **배포(deploy)** — 내 앱을 인터넷에 올려 누구나 주소로 접속하게 하는 것.

## 🔧 시작 전
- **앱 폴더에서 `claude` 실행** (예: `03_완성샘플_할일앱` 또는 본인이 개조한 폴더).
- **Vercel 계정** 준비 (vercel.com — GitHub/이메일로 가입). 로그인은 잠깐 직접 합니다.

> ✅ **이 스타터엔 `vercel.json`·`.vercelignore`가 들어 있어** 바로 '정적 사이트'로 배포됩니다.
> (이게 없으면 폴더의 `server.js`를 Vercel이 **Node 함수로 오감지**해 배포 후 500 에러가 납니다 — 아래 트러블슈팅 참고.)
> - `vercel.json` = "빌드 없이 루트를 정적으로" / `.vercelignore` = "server.js·문서는 배포에서 제외".

## ▶ 방식 A — Claude Code로 배포 (메인)

**1) Vercel CLI 준비**
```
Vercel CLI가 설치돼 있는지 확인하고, 없으면 npm으로 전역 설치해줘.
```
✅ `vercel` 명령이 준비됨.

**2) 로그인** (← 이 단계만 내가 직접)
```
Vercel에 로그인해줘. 브라우저나 이메일 인증이 뜨면 내가 마저 할게.
```
✅ Claude가 `vercel login`을 실행 → 안내대로 브라우저/이메일로 **내가 로그인**. "Success" 뜨면 OK.
💡 회사 계정 말고 본인 계정으로. 처음이면 이메일 인증 코드 방식이 제일 쉬움.

**3) 배포**
```
지금 이 폴더(할 일 PWA, 정적 사이트야)를 Vercel에 배포해줘. 빌드 설정은 기본값으로, 프로젝트 이름은 todo-pwa로. 끝나면 접속할 수 있는 주소를 알려줘.
```
✅ 잠시 뒤 **미리보기 주소**(`https://...vercel.app`)가 나옴. 열어서 동작 확인.
⚠️ 중간에 "이미 있는 프로젝트에 연결할까?" 류를 물으면 → "새 프로젝트로" / "기본값으로 진행"이라고 답해줘.

**4) 정식(프로덕션) 주소로**
```
방금 배포를 프로덕션으로 올려줘 (vercel --prod). 공유용 최종 주소를 알려줘.
```
✅ 친구에게 보낼 **최종 주소** 발급. 이게 폰에 설치할 주소.

> 💡 개조하고 다시 올리고 싶을 때: "방금 바뀐 내용 다시 배포해줘 (vercel --prod)" 한 줄이면 됩니다.

## ▶ 방식 B — 직접 명령 (참고/백업)
Claude Code 없이, 터미널(Git Bash)에서 앱 폴더에서:
```bash
npm i -g vercel        # 처음 한 번
vercel login           # 브라우저/이메일 로그인
vercel                 # 미리보기 배포 (프롬프트는 거의 엔터)
vercel --prod          # 정식 주소
```

---

## ▶ 대안 — GitHub → Vercel 대시보드 (자동 배포 원하면)
1. Claude Code: "이걸 GitHub에 새 저장소로 올려줘."
2. [vercel.com](https://vercel.com) → **Add New → Project** → 그 저장소 **Import**
3. 프레임워크 **Other**(정적) 그대로 → **Deploy** → HTTPS 주소 발급
- 장점: 이후 GitHub에 push만 하면 자동 재배포.

---

## 📱 폰에 설치 (배포 후) ⭐
배포 **HTTPS 주소**를 폰 브라우저에서 열고:
- **안드로이드 (Chrome)**: 주소 열면 "홈 화면에 추가" 배너 / 또는 메뉴(⋮) → "앱 설치"·"홈 화면에 추가"
- **아이폰 (Safari)**: 아래 **공유 버튼**(□↑) → "홈 화면에 추가"
→ 홈 화면에 아이콘 생성. 열면 주소창 없는 **앱 모드**.
- **오프라인 확인**: 비행기모드로 켜도 앱이 열림(서비스워커).
- **공유**: 그 주소를 단톡방에 → 친구도 똑같이 설치.

## 🛠 트러블슈팅
| 증상 | 원인 | 해결 |
|---|---|---|
| "홈 화면에 추가"가 안 보임 | HTTPS 아님 / 매니페스트·아이콘 누락 | **배포 주소**(https)에서 열기. 개발자도구 Application→Manifest 확인 |
| 아이콘이 기본 아이콘 | manifest 아이콘 경로/규격 | 192·512 PNG, manifest 경로 점검 후 재배포 |
| 고친 게 폰에 반영 안 됨 | 서비스워커 캐시 | Claude Code: "sw.js 캐시 버전 올려줘" → 재배포 → 폰에서 새로고침 |
| 아이폰에서 설치 메뉴가 없음 | iOS는 Safari 공유로만 | 크롬 말고 **Safari**에서 공유→"홈 화면에 추가" |
| 배포 후 **500 (FUNCTION_INVOCATION_FAILED)** | `server.js`를 Vercel이 Node 함수로 오감지 | `vercel.json`(정적)·`.vercelignore`(server.js 제외) 추가 후 재배포 → **스타터엔 이미 포함**. Claude Code: "정적 사이트로, server.js는 배포에서 빼줘" |
| 배포는 됐는데 빈 화면 | 잘못된 출력 폴더 | "정적 사이트로, 루트(./)를 그대로 배포"라고 다시 |
| `vercel` 로그인 막힘 | 계정/네트워크 | 이메일 코드 방식으로 로그인, 회사망이면 개인 네트워크로 |

> ⚠️ Vercel 무료(Hobby)는 **비상업·개인 학습엔 충분**. 트래픽·요금 정책은 수업 직전 vercel.com에서 한 번 확인.
