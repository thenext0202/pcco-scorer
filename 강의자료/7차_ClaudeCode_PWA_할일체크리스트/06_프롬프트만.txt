────────────────────────────── 0단계 · 받은 앱 실행
이 폴더에 있는 할 일 앱을 로컬 서버로 띄워줘. 브라우저에서 어떤 주소로 열면 되는지 알려줘.


────────────────────────────── 1단계 · 구조 투어(읽기) ⭐
이 폴더의 구조와 각 파일(store.js, actions.js, render.js, app.js)이 무슨 일을 하는지, 그리고 사용자가 할 일을 추가하면 데이터가 어떻게 흐르는지, 코딩 처음 하는 사람도 알게 쉽게 설명해줘.

@actions.js 이 파일이 무슨 일을 하는지, 입력과 출력이 뭔지 한 줄로 설명해줘.


────────────────────────────── 2단계 · 디자인 개조
앱 이름을 '오늘 할 일'로 바꿔줘. 화면 위 제목과 manifest.json의 이름 둘 다.

테마색을 보라에서 청록(#0ea5a4)으로 바꿔줘. styles.css랑 manifest.json, index.html의 theme-color까지 일관되게.


────────────────────────────── 3단계 · 내 이미지로 아이콘 (← 경로를 내 것으로)
앱 아이콘으로 쓸 이미지를 준비했어. 경로는 C:\Users\내이름\Desktop\my-icon.png 야. 이 이미지를 가져와 192×192, 512×512 PNG 아이콘으로 만들어 icons 폴더에 넣고, manifest.json과 index.html(apple-touch-icon)에 연결해줘.


────────────────────────────── 4단계 · 기능 개조 ⭐ (택1, 더 해도 됨)
각 할 일에 '중요(별표)' 표시를 켜고 끄는 기능을 추가해줘. actions.js에 순수 함수로 toggleImportant를 만들고, app.js에서 연결하고, render.js에서 별표를 보여줘. 중요한 건 목록 위로 정렬해줘.

(대안) 맨 위에 '오늘 3/5 완료(60%)' 같은 진행률을 보여줘. render에서 계산해서 표시해줘.

(대안) '완료한 것 숨기기' 토글 버튼을 추가해줘.


────────────────────────────── 5단계 · 캐시 갱신 + 점검
코드를 여러 번 바꿨으니 서비스워커(sw.js)의 캐시 버전을 올려서 새 코드가 반영되게 해줘. 그리고 추가·체크·삭제·저장이 다 잘 되는지, 새로고침해도 유지되는지 점검해줘.


────────────────────────────── 6단계 · GitHub에 올리기
git 저장소를 초기화하고 지금까지 개조한 걸 커밋한 다음, GitHub에 새 저장소로 올려줘. 단계가 있으면 하나씩 알려줘.


────────────────────────────── 7단계 · Vercel 배포 [배]  (자세히: 07_배포_치트시트.md)
Vercel CLI가 설치돼 있는지 확인하고, 없으면 npm으로 전역 설치해줘.

Vercel에 로그인해줘. 브라우저나 이메일 인증이 뜨면 내가 마저 할게.
   (← 여기서 안내대로 내가 직접 로그인)

지금 이 폴더(할 일 PWA, 정적 사이트)를 Vercel에 배포해줘. 빌드는 기본값, 프로젝트 이름은 todo-pwa로. 끝나면 접속 주소를 알려주고, 이어서 프로덕션(vercel --prod)으로도 올려 최종 주소를 줘.


────────────────────────────── 8단계 · 폰에 설치 + 공유 ⭐
   ※ 배포 URL을 '폰 브라우저'에서 열고:
   - 안드로이드(Chrome): "홈 화면에 추가"
   - 아이폰(Safari): 공유 버튼 → "홈 화면에 추가"
   → 내가 개조한 앱이 홈 화면에! 비행기모드로 오프라인 확인 + 단톡방에 링크 공유.


────────────────────────────── 막힐 때 만능 문장
큰 변경이니 먼저 어떻게 할지 설명해줘. 내가 좋다고 하면 진행해.

이 기능을 추가하려는데 어느 파일(레이어)을 고쳐야 하는지 먼저 알려줘. actions·store·render·app 중에서.

이거 했더니 이렇게 안 돼: (증상). 윈도우·Git Bash·Node.js 환경이야. 쉬운 말로 원인 설명하고 고쳐줘.
