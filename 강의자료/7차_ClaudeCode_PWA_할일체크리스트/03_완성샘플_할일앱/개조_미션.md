# 개조 미션 — 받은 앱을 '내 앱'으로 만들기

> 잘 짜인 구조(데이터·동작·화면·연결 레이어) 위에서 **디자인 + 기능**을 더해 보세요.
> Claude Code에 "○○해줘"라고 시켜도 되고, 구조를 보고 직접 한 줄 고쳐도 됩니다.
> 핵심 학습: **구조가 좋으면 '어디를 고칠지'가 바로 보인다** — 미션마다 손댈 레이어를 표시해 뒀습니다.

---

## 🎨 디자인 개조 (가볍게 시작 — 성공 경험)
| 미션 | 손댈 곳 | 프롬프트 예시 |
|---|---|---|
| 앱 이름 바꾸기 | index.html · manifest.json | "앱 이름을 '오늘 할 일'로 바꿔줘 (화면 제목과 매니페스트 둘 다)" |
| 테마색 바꾸기 | styles.css · manifest · meta | "테마색을 보라에서 청록(#0ea5a4)으로 바꿔줘" |
| 밝은 테마로 | styles.css | "어두운 배경 말고 밝은(라이트) 테마로 바꿔줘" |
| 폰트·둥글기·간격 | styles.css | "카드를 더 둥글게, 글자를 좀 크게 해줘" |
| 내 아이콘 | icons/ · manifest | "이 경로의 이미지를 192·512 아이콘으로 만들어 연결해줘: (경로)" |

## ⚙️ 기능 개조 (한 단계 위 — '내 앱'다워짐)
| 미션 | 손댈 곳 | 프롬프트 예시 |
|---|---|---|
| 완료 항목 한 번에 지우기 | actions.js + app.js + 버튼 | "'완료 항목 모두 지우기' 버튼을 추가해줘 (actions에 함수, 화면에 버튼)" |
| 중요 표시(별표) | actions·render·css | "각 할 일에 별표로 '중요' 표시를 켜고 끄는 기능을 추가해줘. 중요한 건 위로 정렬" |
| 카테고리/태그 | actions·render | "할 일에 간단한 카테고리(예: 일/집/공부)를 달고, 카테고리별로 묶어 보여줘" |
| 완료율 통계 | render | "맨 위에 '오늘 3/5 완료(60%)' 같은 진행률을 보여줘" |
| 완료 항목 숨기기 토글 | render·app | "'완료한 것 숨기기' 토글을 추가해줘" |
| 마감일 | actions·render | "할 일에 마감일을 달고, 지난 건 빨갛게 표시해줘" |

> 💡 미션을 시킬 때 **"어느 레이어를 고치는지"**도 같이 말하면(예: "actions에 함수 추가하고 render에 표시") 결과가 더 정확합니다 — 구조를 이해했다는 신호이기도 하고요.

## ✅ 개조 후 체크
- [ ] 디자인 1개 이상 바꿨다 (이름·색·테마 등)
- [ ] 기능 1개 이상 추가했다
- [ ] 새로고침해도 잘 동작한다 (저장 OK)
- [ ] 서비스워커 캐시 버전을 올려 갱신했다 (코드 바꿨으니 v2 → v3)
- [ ] 배포해서 폰에 다시 깔아 내 변경을 확인했다

> 여기까지 하면 — 받은 앱이 아니라 **'내가 만든 앱'**입니다.
