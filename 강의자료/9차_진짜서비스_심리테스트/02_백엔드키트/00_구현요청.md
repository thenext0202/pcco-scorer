# 시작하기 — 이 순서대로 진행하세요

> 이 폴더는 **백엔드 키트**입니다. 뒷단(창고 연결·규칙)은 준비돼 있고,
> 앞단(화면·질문·기능)은 **여러분의 기획안대로** Claude Code가 만듭니다.

## 순서

### 1. 이 폴더에서 Claude Code 실행
탐색기에서 이 폴더를 열고 → 주소창에 `cmd` 입력(또는 터미널 열기) → `claude` 실행.

### 2. 기획안을 `기획안.md`에 넣기
claude.ai에서 '테스트 기획 프롬프트'로 뽑은 **기획안 전체를 복사**해 두고, 둘 중 편한 방법으로:
- **방법 A (추천)**: Claude Code에게 —
  ```
  지금부터 붙여넣는 내용으로 기획안.md 파일을 만들어줘 (기존 내용은 지우고):

  (여기에 기획안 붙여넣기)
  ```
- **방법 B**: `기획안.md`를 메모장으로 직접 열어 붙여넣고 저장.

### 3. 구현 요청 (복붙용) ⭐
```
기획안.md를 읽고, CLAUDE.md의 규칙을 지켜서 이 심리테스트 서비스를 구현해줘.
다 만들면 ① 로컬에서 확인하는 방법 ② 새로 만든 파일 목록 ③ 기획안과 다르게 한 점을 3줄로 보고해줘.
```

### 4. 완료 기준 (스스로 체크)
- [ ] 브라우저에서 열면 **내 기획대로** 테스트가 처음부터 끝까지 진행된다
- [ ] 결과 화면에 유형/등급이 나온다
- [ ] 공유 버튼 자리가 있고 "🔌 창고 연결 대기 중"으로 표시된다 (**지금은 이게 정상!** — 수업 후반에 켜집니다)
