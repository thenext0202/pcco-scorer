# 심리테스트 공유 서비스 — 백엔드 키트 (9차 강의)

내가 기획한 심리테스트를 **진짜 서비스**로 만드는 실습 키트입니다.
코드는 GitHub에, 실행은 Vercel에, 데이터는 Supabase에 — 내 컴퓨터를 꺼도 살아있는 서비스.

## 뭐가 들어있나

| 파일 | 설명 |
|---|---|
| `00_구현요청.md` | ⭐ **여기부터 읽으세요** — 진행 순서와 복붙용 요청 문장 |
| `기획안.md` | 내 기획안을 붙여넣는 자리 |
| `CLAUDE.md` | Claude Code가 지킬 프로젝트 규칙 (자동으로 읽힘) |
| `db.js` | 창고(Supabase) 연결 엔진 — 수정 금지 |
| `config.js` | 창고 열쇠 넣는 곳 (수업 후반에 채움) |
| `supabase_setup.sql` | 창고 개설 SQL (복붙 1회) |
| `참고샘플_동물테스트/` | 완성 예시 — 막혔을 때 갈아타는 안전망 |

## 시작

1. 이 폴더에서 터미널을 열고 `claude` 실행
2. `00_구현요청.md`의 순서대로 진행

## 완성되면

- 내 테스트 URL: `https://내프로젝트.vercel.app`
- 결과 공유 링크: `...vercel.app/?id=abc123` — 친구 폰에서 내 결과가 열립니다
