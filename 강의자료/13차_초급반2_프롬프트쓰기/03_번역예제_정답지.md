# 03. 번역 예제 정답지 — 강사 전용 (배포 금지)

> 13차 · 쓴다 (채점 없음 — claude.ai 직접 실행). 다같이 번역(슬라이드 09) 발문 시나리오 + 완성형 예시 + 순회용 오답 패턴.
> **완성형 예시를 수업 중에 통째로 띄우지 말 것** — 강사 머릿속 커닝페이퍼다.

---

## A. 다같이 번역 — 메모앱 (8분, 문답식)

### 입력: 11차에 다같이 채운 메모앱 구조도 (요약)

| 칸 | 내용 |
|---|---|
| 데이터 | 본문 · 제목(첫 줄 승격) · 만든/수정 시각 · 고정 여부 · 폴더 · **휴지통** · **정렬 설정** |
| 동작 | (시키는 것) 새로 쓰기 · 수정 · 삭제 · 검색 / (알아서) **자동 저장** · 첫 줄 제목 승격 · 휴지통 30일 뒤 비움 |
| 화면 | 목록 · 작성/보기 · (휴지통) — 우리 범위는 **2개**로 잘랐다 |
| 연결 | 동기화 · 로그인 · 공유 → **전부 잘랐다** ("나 혼자, 폰 하나") |

### 발문 시나리오 (칸 순서대로 — 답은 수강생 입에서)

진행 규칙은 11차 해부와 동일: 강사는 질문만, 틀린 답도 일단 적고 "이건 어느 요소지?"로 되묻는다. 질문 뒤 3초는 기다린다.

**① 데이터 → 맥락 + 제약**
- "데이터 칸 첫 줄 — 메모 본문. 변환표에서 어디로 가죠?" → (맥락/제약) → "문장으로 하면?"
- 목표 문장: **"메모는 껐다 켜도 그대로 남아야 한다."**
- "그럼 휴지통은?" → **"지운 메모는 바로 없어지지 않고 휴지통에 남는다."**
- 막히면 쪼개기: "이건 AI한테 '기억해라'라고 시키는 건가요, '이렇게 생겨라'라고 시키는 건가요?"

**② 동작 → 목적 + 제약**
- "동작 칸 아랫줄 — 자동 저장. 사용자가 시킨 게 아닌데 어떻게 쓰죠?"
- 목표 문장: **"저장 버튼 없이, 입력하는 대로 자동 저장된다."**
- "첫 줄 제목 승격은?" → **"목록에는 메모 첫 줄이 제목으로 보인다."**
- 여기서 짚기: "버튼을 누르면 ~된다" 문장이 **실제 버튼 동작**으로 화면에 나타난다 — "여러분이 쓴 '알아서 하는 것' 줄이 앱을 앱답게 만드는 줄입니다."

**③ 화면 → 출력 + 맥락(디바이스)**
- "화면 칸 — 우리 몇 개로 잘랐었죠?" → "그 두 개를 어디에 쓰죠?"
- 목표 문장 2개: **"폰 세로 화면 기준."** (맥락의 Where) / **"화면은 목록과 작성 두 개, 목록에서 누르면 작성 화면으로."** (출력)
- ★ 반드시 짚기: **"방금 이 한 줄('폰 세로 화면')이 첫 실행에서 화면이 깨지느냐를 가르는 열쇠입니다."**

**④ 연결 → 제약**
- "연결 칸 — 우리 뭘 뺐었죠?"
- 목표 문장: **"로그인 없이, 인터넷 없이, 나 혼자 쓰는 걸로."**
- ★ 반드시 짚기: **"연결 칸의 번역은 대부분 '빼기'입니다. 칸이 빈 사람도 이 문장은 쓸 수 있어요 — 비어 있음도 번역이 됩니다."**

**⑤ 조립 (강사가 직접 시연 — 유일하게)**
- "이 문장들을 역할→목적→맥락→제약→출력 순서로 이어 붙이면 끝입니다. 딱 하나만 제가 채울게요 — 맨 앞의 역할 한 줄과 맨 뒤의 종결 한 줄." → "너는 10년차 모바일 UI 디자이너야" / "한 페이지 HTML 한 파일로 만들어줘"
- 이 시연이 11차의 "자르기만 강사가 시연"과 같은 장치 — 뼈대는 수강생 문장, 접착제만 강사.

### 조립 결과 — 완성형 예시 (강사 참고용, 340자)

> 너는 10년차 모바일 UI 디자이너야. 메모를 빨리 적고 다시 찾아보려는 30~40대 직장인이 쓸 간단한 메모앱을 만들어줘. 폰 세로 화면 기준이야. 화면은 두 개 — 목록 화면과 작성 화면. 목록에는 메모 첫 줄이 제목으로 보이고, 누르면 작성 화면으로 넘어가. 저장 버튼 없이 입력하는 대로 자동 저장되고, 껐다 켜도 메모가 그대로 남아야 해. 지운 메모는 바로 없어지지 않고 휴지통 목록에 남겨줘. 디자인은 흰 배경에 검정·회색 톤, 둥근 모서리, 이모지 금지. 로그인 없이, 인터넷 없이, 나 혼자 쓰는 걸로. 한 페이지 HTML 한 파일로 만들어줘.

- 이 정도 밀도면 claude.ai Artifacts가 **한 번에 작동하는 앱**을 내놓는다 — 5요소가 다 차 있고 디바이스·인터랙션·단일 파일 종결까지 갖춘 상태
- localStorage를 명시하지 않아도 "껐다 켜도 남아야 해"면 충분 — 기술 용어를 시키지 말 것 (초급반은 묘사로 말한다)

## B. 순회용 — 흔한 오답 5패턴 + 처방 (답을 주지 말고 질문만)

| # | 패턴 | 증상 (화면에서 보이는 것) | 처방 질문 |
|---|---|---|---|
| 1 | **Where 누락** (가장 흔함) | PC 기준으로 나와 폰에서 글자·버튼이 깨짐 | "구조도 화면 칸에 뭐라고 그렸어요? 폰이에요 PC예요? — 그걸 왜 안 적었어요?" |
| 2 | 목적이 결과물 종류뿐 | "메모앱 만들어줘"에서 시작 | "누가, 언제, 왜 쓰는 앱이에요? 11차에 한 문장으로 정했었잖아요 — 그 문장 어디 갔어요?" |
| 3 | 제약 0~1개 | 디자인·분량·기술·금지 중 하나만 | "화면에 뭐가 어떻게 보였으면 좋겠어요? 그게 디자인 제약이에요. 이모지 싫으면요? 그게 금지예요" |
| 4 | 출력 종결 문장 없음 | 앱 대신 설명 텍스트가 옴 | "마지막 한 줄 — 워크시트 4쪽 맨 아래 고정 문장 그대로: '한 페이지 HTML 한 파일로 만들어줘'" |
| 5 | 과욕 스코프 | Artifacts가 헤매거나 절반만 만들어 옴 | "「이번엔 안 만들 것」 3줄, 기억나요? (11차 4쪽 — 종이가 없으면 지금 구두로 셋 정하게 한다) 잘랐던 게 다시 들어와 있어요" |

패턴 5의 처방이 중요 — **11차 워크시트 4쪽이 여기서 재등장**한다. "안 만들 것"은 버린 게 아니라 미룬 것이었고, 그걸 프롬프트에서도 지키는 게 오늘의 범위 관리다.

## C. 강사 시연용 입력 (라이브 실행 데모 1회 — 슬라이드 11에서)

수강생 것 말고 **4강 라이브 데모 입력을 재활용**한다 (작동 검증됨):

> 너는 모바일 앱 UI 디자이너야. 회식 자리에서 직장인들이 분위기 풀려고 핸드폰으로 잠깐 보는 앱을 만들거야. 사용자는 30~40대 직장인, 5초 안에 결과를 봐야 해. 버튼 하나 누르면 오늘의 회식운이 나오고, 다시뽑기 가능하게. 너무 진지하지 않고 살짝 유머 있게. 한 페이지 HTML로 만들어줘.

시연 순서: claude.ai 새 대화에 붙여넣기 → 전송 → 미리보기에 앱이 뜨는 것까지 40초 안에 — **"이 정도 묘사면 이렇게 나옵니다. 여러분 것도 잠시 후에 이렇게 뜹니다."** 생성 대기 중 침묵하지 말고 "기다리는 동안 다음 문장을 고치면 됩니다"로 루프의 리듬을 미리 보여준다. 실패하면 당황하지 않고 "다시 실행" — 그 자체가 오늘 배울 루프다.

## D. 좋은 프롬프트 커닝페이퍼 (순회 중 즉답용 — 5요소 관점)

- **역할** = 경력 + 세부 분야 ("천재"·"세계 최고" 과장은 무의미) / **목적** = 용도 + 사용자 행동
- **맥락** = Who·Where·When — **Where(디바이스) 빠지면 PC 기준으로 나와 폰에서 깨진다** (가장 흔한 결함)
- **제약** = 디자인·분량·기술·금지 4카테고리 중 3개 이상 / **출력** = 파일 종류 + 화면 구성 + 종결 문장 고정
- 피해야 할 것: 모호한 형용사("예쁘게")·부정형 남발·모순 지시·과욕 스코프(Artifacts가 헤맨다)
- 길이 250~500자 권장 — 길다고 좋은 게 아니다
