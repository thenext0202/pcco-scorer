## 실력은 두 번째 실행에서 는다.

### 변환표 4줄 치트시트 — 칸이 요소로 갑니다

| 그린 칸 | 프롬프트 어디로 | 예 |
|---|---|---|
| **데이터** | 맥락 + 제약 | "할 일은 껐다 켜도 남아야 한다" |
| **동작** | 목적 + 제약 | "체크하면 아래로 내려간다" |
| **화면** | 출력 + **맥락(디바이스)** | "폰 세로 화면, 단일 파일" |
| **연결** | 제약 | "로그인 없이, 링크로 공유" |

### 5요소 한 줄 요약 (좋은 묘사의 다섯 칸)

| 요소 | 한 줄 | 예 |
|---|---|---|
| 역할 | 어떤 전문가 시점인가 | "너는 10년차 모바일 UI 디자이너야" |
| 목적 | 누가 왜 쓰는 앱인가 | "물 마신 잔 수를 기록하려고" |
| 맥락 | 누가 · **어떤 기기에서** · 언제 | ★ **디바이스를 안 적으면 PC 기준으로 나와 폰에서 깨짐** |
| 제약 | 디자인 · 분량 · 기술 · 금지 | "흰 배경, 한 화면, 이모지 금지" |
| 출력 | 파일 종류 + 화면 구성 | "한 페이지 HTML 한 파일" |
