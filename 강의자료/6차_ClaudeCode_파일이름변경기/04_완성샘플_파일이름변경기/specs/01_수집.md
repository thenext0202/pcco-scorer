# 01 · 수집(Collect) 단계 지침

## 역할
폴더 경로를 받아, 그 안의 '파일 목록'을 만든다. (`src/collect.js`)

## 입력
- `folderPath` (문자열) — 사용자가 지정한 폴더

## 출력 (다음 단계로 넘김) — I/O 계약
- **포(Format)**: JSON `{ folderPath, totalCount, sortBy, files[] }`
- **필(Required)**: `files[]` 각 항목 = `originalName, baseName, ext, index`
- **범(Scope)**: 폴더 *바로 아래 파일만*(하위 폴더 제외). 최대 500개
- **메(Metadata)**: `totalCount`, `sortBy`(기본 이름순)

## 책임 (이 단계만)
- 폴더 읽기, 파일/폴더 구분, 이름 분리(baseName + ext)
- 위험 경로(드라이브 루트·시스템 폴더) 거부
- `.rename-history.json`은 목록에서 제외

## 절대 하지 않는 것
- 이름 바꾸기 ❌ (3단계 출력의 책임)
- 새 이름 계산 ❌ (2단계 변환의 책임)
