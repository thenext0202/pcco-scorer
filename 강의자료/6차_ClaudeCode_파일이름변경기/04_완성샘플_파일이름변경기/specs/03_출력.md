# 03 · 출력(Output) 단계 지침

## 역할
검증된 변경계획대로 **실제 파일 이름을 제자리에서 바꾼다.** (`src/output.js`)

## 입력 (이전 단계에서 받음)
- 계약2 '변경계획 JSON' (검증 완료본) + `folderPath`

## 출력
- 제자리 `fs.rename` 실행 결과 `{ applied, skipped, history }`
- 되돌리기 기록 파일 `.rename-history.json`

## 책임 (출력만)
- `conflict=true` 또는 `new === old`는 건너뛴다.
- 이름 맞교환(A↔B) 대비 **2단계 처리**(임시 이름 경유).
- 적용 내역을 `.rename-history.json`에 기록.
- `undo()`: 기록을 읽어 `to → from`으로 역방향 복원.

## 절대 하지 않는 것
- 새 이름 계산 ❌ (2단계 변환의 책임)
- 검증 없이 변경 ❌ (반드시 검증된 plan만 받는다)
- 지정 폴더 밖 / 하위 폴더 건드리기 ❌
