# 파일 이름 일괄 변경기

내 폴더의 파일 이름을 규칙대로 **제자리에서** 바꿔주는 로컬 도구.
적용 전 **미리보기**, 잘못되면 **되돌리기**를 지원합니다. (파일은 내 컴퓨터 밖으로 안 나갑니다.)

## 설치
1. [Node.js](https://nodejs.org) 설치 (LTS)
2. 이 저장소 받기: `git clone <저장소 주소>`

## 실행
```bash
node server.js
```
브라우저에서 http://localhost:3000 열기.
(포트를 바꾸려면 `.env`의 `PORT` 수정)

## 바로 해보기 (연습용 폴더 포함)
1. **자체 테스트**: `node test.js` → 9개 점검이 모두 ✅ 면 정상.
2. **실제로 써보기**: `node server.js` 실행 → 브라우저에서 폴더 칸에
   이 프로젝트의 **`테스트용_연습폴더`** 경로를 붙여넣기 → 규칙 고르고 미리보기 → 적용 → 되돌리기.
   - 연습폴더에는 이름 엉망인 더미 파일 6개가 들어 있어, 바로 테스트할 수 있습니다.

## 사용법
1. **폴더** 경로 입력 (연습용 폴더로 먼저!)
2. **규칙** 선택 — 접두사 / 접미사 / 찾기·바꾸기 / 공백 / 소문자 / 순번
3. **미리보기** 클릭 → 원래 이름 → 새 이름 표 확인 (충돌은 빨강)
4. 충돌 없으면 **적용**
5. 잘못됐으면 **되돌리기**

## 안전
- 미리보기·검증을 통과해야만 실제 변경
- 지정 폴더 *바로 아래 파일*만 (하위 폴더 안 건드림)
- 시스템 폴더·드라이브 루트는 거부
- 직전 변경은 `.rename-history.json` 기록으로 되돌리기 가능

## 구조 (개발자용)
`수집 → 변환계획 → 검증 → 출력` 4모듈 파이프라인. 자세한 계약은 `specs/`, `CLAUDE.md` 참고.
