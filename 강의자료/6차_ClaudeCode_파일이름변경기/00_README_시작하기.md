## ▶ 샘플 프로그램 바로 실행 (Claude Code로 열어서 테스트)

1. **Claude Code 열기**
   - 터미널에서 `04_완성샘플_파일이름변경기` 폴더로 이동 → `claude` 실행
   - 또는 그냥 그 폴더에서 아래 명령을 직접 실행해도 됩니다.

2. **자체 테스트** (코드가 멀쩡한지 9개 점검)
   ```bash
   node test.js
   ```
   → 모두 ✅ 면 정상.

3. **실제로 써보기**
   ```bash
   node server.js
   ```
   → 브라우저에서 http://localhost:3000 열기
   → 폴더 칸에 이 프로젝트의 **`테스트용_연습폴더`** 경로 붙여넣기
   → 규칙(접두사/순번/찾기바꾸기…) 고르고 **미리보기** → **적용** → **되돌리기**

> 💡 추가 설치가 전혀 없습니다(Node 내장 모듈만). Claude Code가 깔려 있으면 Node도 이미 있습니다.

### Claude Code로 "직접 만들어보는" 실습이라면
`02_구조설계안.md`의 R-PCCO 묘사 프롬프트(8-1 단순 버전 → 8-2 레이어 버전)를 그대로 Claude Code에 던지며 따라가면 됩니다. 완성본(④)은 정답 비교용으로 두세요.
