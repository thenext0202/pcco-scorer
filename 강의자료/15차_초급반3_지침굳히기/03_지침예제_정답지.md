## A. 강사 데모 — 「강의 기획 작업실」 지침 (슬라이드 03, 6분)

수업 전 강사 claude.ai 계정에 프로젝트 「강의 기획 작업실」을 만들고 아래 지침을 등록해둔다. **실제 쓰는 지침을 수업용으로 정리한 판** — 내부 정보(수강생 이름·요금·플랫폼 내부 구조)는 뺐다. 실제 본인 지침이 더 설득력 있으면 그걸 써도 되지만, 화면에 띄우기 전에 K 지식 칸의 내부 정보를 한 번 훑는다.

```
## 정체성
너는 '기획실장'이라는 10년차 강의 기획자다. 성격: 표로 말한다, 시간부터 센다, 근거 없는 칭찬은 하지 않는다.

## 임무
① 주제 한 줄을 받으면 강의 기획안 초안을 만든다 ② 120분 타임라인을 분 단위로 배분한다 ③ 리스크표를 만든다.
그 외 요청(슬라이드 제작·원고 작성 등)은 한 줄로 답하고 "기획안부터 확정하자"고 본업으로 돌린다.

## 규칙
- 총 시간은 120분 기준. 강의부가 60% 이상이어야 한다 (초심자 반은 개념 설명이 실습보다 오래 걸리므로).
- 새 개념 하나당 슬라이드 하나. 한 슬라이드에 개념 둘을 넣지 않는다.
- "~할 수 있다", "다양한", "효과적으로" 같은 추상 표현 금지. 숫자나 실물 예로 바꾼다.
- 모든 표는 3열 이하. 4열이 필요하면 표를 둘로 나눈다.
- 모르는 것은 추측하지 말고 [확인 필요]로 표시한다.

## 지식
[수강생] 초급반 = 개발 경험 없는 성인. 격주 120분. 각자 노트북 또는 폰. claude.ai 무료 플랜 사용.
[지난 회차] 11차 구조 그리기(레이어 4겹) → 13차 프롬프트 쓰기(변환표 4줄) → 15차 지침(I-MRKO).
[원칙] 오프닝은 직전 강의 한 장 복습. 수강생 숙제를 수업 중 꺼내게 하지 않는다. 첫 개념은 비유→정의→왜→실물 순서.

## 출력
항상 이 순서, 마크다운 헤더 고정: ## 개요 (표) → ## 타임라인 (표, 분 단위) → ## 리스크 (표) → ## 산출물 목록. 각 표 앞에 한 문장 설명. 전체 800자 이내.
```

### 데모 순서 (6분)

| 순서 | 화면 | 멘트 |
|---|---|---|
| (a) 1분 | 지침 **없는** 새 대화에 `다음 주 초급반: 지침` 전송 | "제가 늘 하는 일이 강의 기획입니다. 한 줄만 던져볼게요." → 되묻거나, 산문으로 길게, 시간 배분 없음 |
| (b) 2분 | 프로젝트 「강의 기획 작업실」 안 새 대화에 **같은 한 줄** 전송 | "이번엔 같은 한 줄을 다른 곳에 넣습니다." → 개요표·타임라인·리스크표·산출물이 늘 쓰던 순서로 |
| (c) 1분 | 프로젝트 지침 화면을 연다 | "차이는 이겁니다 — 제가 미리 써둔 한 페이지. 요청은 똑같이 한 줄이었어요." 헤더 5개를 손가락으로 훑는다(정체성·임무·규칙·지식·출력) — **읽지 않는다**, 생김새만 |
| (d) 1분 | (b)를 재료 하나 더로 반복: `중급반: 데이터 구조` | "재료를 바꿔도 틀이 같죠. 이게 오늘 여러분이 만들 겁니다." |
| 예비 | (b)가 흔들리면 | "다시 실행" — "이게 오늘의 루프예요. 지침도 한 번에 안 굳습니다." |

수업 전 **재료 3개로 3회 시험**해 (b)가 안정적으로 같은 틀을 내는지 확인한다. 무료 플랜에서 프로젝트 지침이 안 되면 (b)를 "대화 맨 앞 붙여넣기"로 바꿔 시연하고 슬라이드 16의 3갈래 순서도 바꾼다.

### ✅ 시험 결과 (2026-09-09, 강사 계정 Max 플랜 — 프로젝트 「강의 기획 작업실 (15차 데모)」 생성·지침 등록 완료)

| 입력 | 결과 |
|---|---|
| (b) 재료 1 "다음 주 초급반: 지침" | 개요→타임라인→리스크→산출물 순서 · 표 3열 · 강의 62.5% · [확인 필요] 표시 — **틀 유지**. 단, 지식에 15차가 "지난 회차"로 있어 "다음 주"를 **17차로 해석**함 |
| (b) 재료 2 "중급반: 데이터 구조" | 같은 틀. 중급반 정의가 지식에 없어 [확인 필요]로 되물음(지침대로) |
| (b) 재료 3 "특강: AI로 영상 만들기" | 같은 틀. 강의 65% |
| (a) 지침 없는 새 대화 "다음 주 초급반: 지침" | **되묻기** — "어떤 초급반인가요? 지침은 어떤 형태? 기존 자료 있나요?" (데모 (a) 의도대로) |

**수업 당일 주의 2가지**
1. (a)의 되묻기는 **계정 메모리 상태에 따라 달라질 수 있다** (강사 계정은 초급반 대화 이력이 많음). 수업 직전 (a)를 한 번 더 돌려 확인하고, 되묻지 않으면 "형식이 제멋대로·시간 배분 없음"을 차이점으로 짚는다. 시크릿 창(비로그인은 불가)이나 메모리 끈 새 대화가 더 안전
2. "다음 주 초급반: 지침"이 17차로 해석되는 것을 피하려면 데모 입력을 **"초급반 15차: 지침"** 또는 **"초급반: 반복을 지침으로"**로. 슬라이드 03·러닝시트 03의 입력 문구는 "다음 주 초급반: 지침" 그대로 두어도 무방(데모 흐름엔 영향 없음)

## B. 다같이 지침 쓰기 — 「주간 보고 작업실」 (슬라이드 15, 8분, 문답식)

11차 해부·13차 번역과 같은 방식: 강사는 질문만, 문장은 수강생 입에서, 강사는 받아 적는다. 틀린 답도 일단 적고 "이건 다섯 칸 중 어디지?"로 되묻는다. 질문 뒤 3초는 기다린다.

### 발문 시나리오 (칸 순서대로)

**I 정체성**
- "매주 월요일 팀장한테 내는 주간 보고 — 이걸 대신 써줄 AI가 있다면, 이름을 뭐라고 붙일까요?" → (아무 이름) → "직업은요? 경력은?" → "성격은 두 개만 — 이 사람이 보고서를 어떻게 쓰면 좋겠어요?"
- 목표: **"너는 '보고왕'이라는 8년차 사무직 팀원. 성격: 숫자 먼저, 사족 없음."**
- 누가 "세계 최고의 보고서 작성자"라고 하면 → "세계 최고면 어떻게 쓰죠? — 모르죠. 실재할 법한 사람이 제일 잘 먹힙니다."

**M 임무**
- "이 AI한테 주로 시킬 일 두 가지만." → 목표: **"① 이번 주 한 일 메모를 주간 보고로 정리 ② 다음 주 계획 3줄 뽑기"**
- "다른 걸 시키면요? 예를 들어 이메일 써달라고 하면?" → **"한 줄로 답하고 '주간 보고부터'로 돌린다"** — "범위 밖 처리 한 줄이 있어야 뭐든 다 하는 AI가 안 됩니다."

**R 규칙 ★ (가장 오래)**
- "보고서, 어떻게 써야 해요?" → (보통 "간결하게", "보기 좋게") → **"간결하게 — 몇 줄이요?"** → "결론 1줄 + 항목 3개" → "보기 좋게 — 뭐가 보기 좋은 거죠?" → "표로, 3열"
- "팀장님이 싫어하는 표현 있어요?" → 금지어 ("~것 같습니다" 금지, 이모지 금지)
- "왜 3줄이에요?" → 이유 붙이기: **"팀장이 회의 전 1분 안에 읽어야 하므로"**
- 목표: **"결론 1줄 + 항목 3개 이내 (팀장이 1분 안에 읽으므로) / 표는 3열 / '~것 같습니다' 금지 / 이모지 금지"**
- ★ 반드시 짚기: **"방금 '간결하게'가 '결론 1줄 + 3개'로 바뀌었죠. 이 한 번의 번역이 오늘 세 산출물이 흔들리느냐를 가릅니다."**

**K 지식**
- "매주 보고서 쓸 때마다 AI한테 다시 설명하던 게 뭐예요?" → (팀 이름, 팀장 성향, 프로젝트 이름, 지난 주 형식)
- 목표: **"[팀] 마케팅팀 5명, 보고 대상은 팀장 / [진행 중] 프로젝트 A·B / [형식] 지난 주 보고서 구조 그대로"**
- ★ 반드시 짚기: **"이 칸에 비밀번호·고객 개인정보·매출 숫자 넣지 마세요. 가명이나 [자리표시]로."**
- 지식 vs 임무 헷갈리면: "참고하는 것인가, 하는 것인가?"

**O 출력**
- "보고서가 매번 어떤 순서로 나오면 좋겠어요?" → 목표: **"항상 ① 이번 주 결론 1줄 ② 한 일 (표 3열: 항목/결과/비고) ③ 다음 주 계획 3줄 — 이 순서, 헤더 고정"**

**조립 (강사가 직접 시연 — 유일하게)**
- "이 문장들을 헤더 5개 밑에 넣으면 끝입니다. 제가 하는 건 `## 정체성` 같은 헤더 다섯 개뿐이에요 — 뼈대는 다 여러분 문장입니다."

### 조립 결과 — 완성형 (강사 참고용, 약 450자 — 수업 중 통째로 띄우지 않기)

```
## 정체성
너는 '보고왕'이라는 8년차 사무직 팀원이다. 성격: 숫자 먼저, 사족 없음.

## 임무
① 이번 주 한 일 메모를 주간 보고로 정리한다 ② 다음 주 계획 3줄을 뽑는다. 그 외 요청은 한 줄로 답하고 "주간 보고부터"로 돌린다.

## 규칙
- 결론 1줄 + 항목 3개 이내 (팀장이 회의 전 1분 안에 읽으므로)
- 표는 3열 이하
- "~것 같습니다" 금지. 이모지 금지
- 메모에 없는 성과를 지어내지 않는다. 빈 곳은 [확인]으로 남긴다

## 지식
[팀] 마케팅팀 5명. 보고 대상은 팀장. [진행 중] 프로젝트 A(신제품 런칭), B(홈페이지 개편). [형식] 지난 주 보고서 구조를 그대로 따른다.

## 출력
항상 이 순서, 헤더 고정: ## 이번 주 결론 (1줄) → ## 한 일 (표: 항목/결과/비고) → ## 다음 주 계획 (3줄).
```

시험 재료 3개(구두로): "이번 주: A 광고 소재 3종 제작, B 시안 미팅 / 다음 주: A 집행 시작" · "이번 주: B 개편 1차 오픈, 버그 12건 수정" · "이번 주: 휴가 2일, A 성과 리포트 초안".

## C. 순회용 — 흔한 오답 5패턴 + 처방 (답을 주지 말고 질문만)

| # | 패턴 | 증상 (세 산출물에서 보이는 것) | 처방 질문 |
|---|---|---|---|
| 1 | **규칙이 형용사** (가장 흔함) | 셋이 길이·순서·말투가 제각각 | "'간결하게'가 몇 줄이에요? 그 숫자를 적으세요" |
| 2 | **지식 비어 있음** | 재료 한 줄에 되묻는다 ("어느 팀이죠?") | "매주 다시 설명하던 게 뭐예요? 그걸 지식 칸에" |
| 3 | **임무 없음 / "뭐든 도와줘"** | 재료를 엉뚱한 형식으로 (보고서 대신 이메일) | "이 AI가 주로 하는 일 두 개만. 다른 건 어떻게 하라고 할까요?" |
| 4 | **예시의 함정** — 지난 보고서·기획안 통째로 붙임 | 세 산출물이 그 예시를 베낀다 (같은 숫자·같은 문장) | "그건 지식이 아니라 예시예요. 형식만 규칙으로 옮기고 본문은 빼세요" |
| 5 | **출력 없음** | 셋의 섹션 순서가 다르다 | "매번 어떤 순서로 나오면 좋겠어요? 그 순서를 헤더로" |

추가 순회 포인트: 지식 칸에 실명·전화번호·매출액·비밀번호가 보이면 조용히 "가명이나 [자리표시]로 바꾸세요" (슬라이드 12 보안 주의).

## D. 좋은 지침 커닝페이퍼 — 5요소 관점 순회용 (점수 없이)

| 칸 | 있으면 좋은 것 | 없으면 보이는 증상 |
|---|---|---|
| I | 이름 + 경력/분야 + 성격 2~3개. 과장 없음 | 말투가 대화마다 바뀜 |
| M | 구체 업무 2~3개 + 범위 밖 처리 한 줄 | 엉뚱한 형식, 뭐든 해줌 |
| R | 숫자 / 금지어 / 고정 포맷 중 하나로. 이유("~이므로") 붙으면 새 상황에도 응용 | 셋이 제각각 |
| K | 참고 자료 1~3종 + 각각 언제 쓰는지. 민감 정보 없음 | 되묻기, 배경 무시 |
| O | 순서 + 섹션 + 길이. 헤더 고정 | 섹션 순서가 다름 |

길이 300~700자. 예시 0개(고정 포맷 템플릿 1개는 예외).
