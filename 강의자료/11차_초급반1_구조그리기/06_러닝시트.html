📖 사용법

한 페이지 = 한 슬라이드. ★ KEY POINT(청록) = 반드시 전달할 한 문장 · 🖥 화면(파랑) = 이 슬라이드에 띄울 것 · 💬 이렇게 말하세요(검정) = 실제 멘트 · 💡 강사 팁(노랑) · ⚠️ 주의(빨강) · 📌 참고(회색) · → 넘어가며.
이 수업은 채점 플랫폼을 쓰지 않는다 — 오늘의 산출물은 점수가 아니라 워크시트에 그려진 구조도 1장이다.

📚 핵심 개념 한 줄 (강사용)

레이어 4겹 = 데이터(뭘 기억하나) · 동작(뭘 하나) · 화면(어떻게 보이나) · 연결(밖과 어떻게 닿나) — 6차 용어 그대로
핵심 메시지 = "그릴 수 없으면 시킬 수 없다" · 후렴 = "화면에 안 보인다고 없는 게 아니다"
성공 판정 = 잘 그린 구조도 수가 아니라 「연결」 칸을 채운 사람 수 · 13차 연결 = 오늘 워크시트가 13차의 재료
수업 전 준비 = ① 02 워크시트 인쇄(인원+여유) ② 03 정답지(강사만) ③ 04 예비소재 리스트 2~3부 ④ 화이트보드·마커 ⑤ 타이머 ⑥ 조 편성(3~4인)

01Part 0 · 오프닝
표지 — "오늘은 문장을 쓰지 않습니다"
⏱ 2분 (00–02)
★ KEY POINT
앱 = 화면이 아니라 앱 = 네 칸. 오늘은 프롬프트를 한 줄도 안 쓰고, 그림만 그린다.
🖥 화면
표지 — "앱 = 화면"에 취소선, 그 아래 "앱 = 네 칸". 우측에 데·동·화·연 4줄.
💬 이렇게 말하세요
안녕하세요, 초급반 첫 시간입니다. 미리 말씀드리면 — 오늘은 프롬프트를 한 문장도 쓰지 않습니다. 대신 그림을 그립니다. 지난 진단 때 다들 느끼셨을 거예요. 뭘 써야 할지 모르겠는 그 막막함. 그건 문장력 문제가 아니었습니다. 머릿속에 그릴 게 없어서였어요. 오늘 그 그림 그리는 법부터 갑니다.
💡 강사 팁
말하는 동안 워크시트를 지금 배포한다 — 뒤에서 앞으로 넘기게 하면 멘트 끊기지 않는다. "지금 나눠드리는 종이가 오늘의 전부입니다. 펜만 있으면 됩니다."
→ 넘어가며: "왜 그릴 게 없느냐 — 범인부터 잡고 시작하죠."

02Part 0 · 오프닝
왜 안 그려지나 — 우리는 앱을 화면으로만 본다
⏱ 6분 (02–08)
★ KEY POINT
프롬프트를 못 쓰는 게 아니라, 그릴 게 없어서 못 쓰는 것 — 화면 뒤의 세 가지가 안 보이기 때문.
🖥 화면
"우리가 보는 것(버튼·목록·색깔)" / "있어야 하는 것(남는 것·저절로 일어나는 일·안 가본 화면·밖과 닿는 통로)" 대비.
💬 이렇게 말하세요
여러분 오늘 아침부터 지금까지 앱 몇 개나 쓰셨어요? 카톡, 지도, 유튜브… 수십 개죠. 그런데 그중 하나를 골라서 "이거랑 똑같은 거 만들어줘"라고 AI한테 시킨다고 해보세요. 뭐라고 쓰실 건가요? …버튼이 있고, 목록이 있고. 그게 다예요. 우리는 앱을 매일 쓰지만 화면으로만 봅니다. 그런데 앱이 되려면 화면 말고 세 가지가 더 있어야 해요. 껐다 켜도 남아 있는 것. 아무도 안 눌렀는데 저절로 일어나는 일. 그리고 바깥세상과 닿는 통로. 이게 안 보이니까 그릴 게 없고, 그릴 게 없으니까 쓸 게 없는 겁니다.
💡 강사 팁
"오늘 아침부터 앱 몇 개나?"는 실제로 손을 들게 하지 말고 수사적 질문으로 빠르게. 여기서 시간을 쓰면 뒤가 밀린다.
→ 넘어가며: "그래서 오늘의 문장이 이겁니다."

03Part 0 · 오프닝
핵심 메시지 — 그릴 수 없으면 시킬 수 없다
⏱ 2분 (08–10)
★ KEY POINT
그림이 생기면 프롬프트는 '옮겨 적는 일'이 된다 — 오늘 하루를 지배하는 한 문장.
🖥 화면
"그릴 수 없으면 시킬 수 없다" 중앙에 크게.
💬 이렇게 말하세요
그릴 수 없으면, 시킬 수 없다. 오늘 이 문장 하나만 가져가시면 됩니다. AI는 여러분이 시키는 대로 만듭니다. 그런데 시키려면 내 머릿속에 먼저 그림이 있어야 해요. 거꾸로 말하면 — 그림만 있으면, 프롬프트는 그걸 문장으로 옮겨 적는 일밖에 안 됩니다. 쓰는 게 어려운 게 아니라 그리는 게 어려운 거고, 그래서 오늘은 그리는 법만 합니다.
→ 넘어가며: "이 수업이 어디로 가는지, 지도부터 보여드릴게요."

04Part 0 · 오프닝
초급반 안내 — 하나의 소재로 3주 관통
⏱ 5분 (10–15)
★ KEY POINT
11 그린다 → 13 쓴다 → 15 굳힌다 (지금 잡힌 계획 3회 — 초급반 자체는 계속 이어진다). 소재는 하나를 3주 관통 — 여기서 못 박는다.
🖥 화면
3단계 카드(11 그린다[오늘, 강조] / 13 쓴다 / 15 굳힌다) + "오늘 나가는 준비물은 내 구조도 1장".
💬 이렇게 말하세요
초급반은 오늘로 끝나는 게 아니라 계속 이어집니다. 먼저 세 번의 계획이 잡혀 있어요. 오늘은 그립니다 — 만들고 싶은 것의 구조를 네 칸으로. 다음 시간엔 씁니다 — 오늘 그린 그림을 프롬프트로 바꿔서 실제로 만듭니다. 마지막 시간엔 굳힙니다 — 만들면서 반복된 작업을 지침으로 만들어요. 그리고 제일 중요한 규칙 하나. 소재는 각자 자유입니다. 진짜 만들고 싶은 걸 정하세요. 대신 — 한 번 정하면 3주 내내 그거 하나로 갑니다. 오늘 그린 그림이 다음 시간에 진짜로 만들어지고, 그다음 시간에 지침으로 굳는 거예요. 그러니까 오늘 수업 끝나고 나가실 때 손에 들려 있어야 하는 건 딱 한 장 — 내 구조도입니다.
⚠️ 주의
"소재 3주 관통"을 여기서 확실히 못 박을 것 — 뒤(실습 3)에서 소재를 정할 때 "다음 주에 바꾸면 안 되나요?"가 나오면 이 슬라이드를 다시 가리킨다. 바꾸면 3주 서사가 끊긴다.
→ 넘어가며: "그럼 그 네 칸이 뭔지 — 오늘의 프레임워크입니다."

05Part 1 · 프레임워크
레이어 4겹 — 데이터 · 동작 · 화면 · 연결
⏱ 3분 (15–18)
★ KEY POINT
어떤 앱이든 네 칸으로 쪼개진다 — 칸마다 스스로에게 던지는 질문이 하나씩 있다.
🖥 화면
4칸 카드 — 연결 칸만 청록 배경으로 강조. "네 번째 칸이 오늘의 승부처".
💬 이렇게 말하세요
네 칸입니다. 데이터 — 뭘 기억하나. 동작 — 뭘 하나. 화면 — 어떻게 보이나. 연결 — 밖과 어떻게 닿나. 워크시트 1쪽에 이 표가 그대로 있어요. 칸마다 질문이 하나씩 붙어 있죠? 이 질문이 오늘의 도구 전부입니다. 그리고 네 번째 칸, 연결 — 얘가 오늘의 승부처인데, 왜인지는 조금 있다가 알게 됩니다.
📌 참고
"레이어 4겹"은 6차(Claude Code 실전)에서 쓴 용어 그대로다. 6차를 들은 수강생에게는 "그때 그 네 겹입니다"라고 연결해줘도 좋다 — 단 6차 내용 복습으로 새지 말 것.
→ 넘어가며: "첫 번째 칸부터 — 뭘 기억하나."

06Part 2 · ① 데이터
① 데이터 — 뭘 기억하나
⏱ 7분 (18–25)
★ KEY POINT
판별 질문 하나 — "껐다 다시 열면 뭐가 그대로여야 하나?" 휴지통도, 정렬 설정도 데이터다.
🖥 화면
"쉽게 나옴(본문·시각·고정·폴더) / 잘 안 떠오름(휴지통·정렬 설정)" + 30초 퀴즈(쇼핑 장바구니).
💬 이렇게 말하세요
데이터를 찾는 질문은 하나예요. 앱을 완전히 껐다가 다시 열었을 때, 뭐가 그대로 있어야 하나? 메모앱으로 해보죠. 메모 내용 — 당연히 남아야죠. 만든 시각, 고정해둔 것, 폴더 — 이런 건 쉽게 나옵니다. 그런데 두 개가 잘 안 나와요. 하나, 휴지통. 지운 메모가 30일 동안 살아 있죠? 지운 것도 기억하고 있다는 겁니다. 둘, 정렬 설정. 최신순으로 바꿔놓으면 다음에 켜도 최신순이죠? 설정도 데이터예요. 자 30초 퀴즈 — 쇼핑 앱 장바구니. 껐다 켜도 남아 있어야 하는 게 뭐뭐일까요? 옆 사람과 30초.
💡 강사 팁
퀴즈 답은 2~3개만 받고 끊는다(담은 상품·수량·옵션 — "가격이 바뀌면?"까지 나오면 최상). 레이어마다 30초 퀴즈가 리듬 장치다 — 길어지면 다음 퀴즈를 줄인다.
→ 넘어가며: "두 번째 칸 — 오늘 첫 번째 하이라이트입니다."

07Part 2 · ② 동작 ⭐
② 동작 — 뭘 하나 · "저장 버튼이 없는데 저장이 된다"
⏱ 8분 (25–33)
★ KEY POINT
동작은 두 줄 — 사용자가 시키는 것 / 앱이 알아서 하는 것. 두 번째 줄이 안 보이는 줄이다.
🖥 화면
"사용자가 시키는 것 / 앱이 알아서 하는 것" 대비 + "그럼 그 일을 한 건 누구입니까?" 콜아웃.
💬 이렇게 말하세요
동작 칸은 두 줄로 나눠 적습니다. 윗줄 — 사용자가 시키는 것. 쓰고, 지우고, 검색하고. 이건 쉬워요. 문제는 아랫줄입니다. 아무도 안 시켰는데 일어나는 일. 여러분, 메모앱에서 저장 버튼 눌러보신 적 있어요? …메모앱엔 저장 버튼이 없습니다. 없는데, 저장은 되죠. (3초 침묵) …그럼 그 일을 한 건 누구입니까?
⚠️ 주의 — 3초의 침묵
"있습니까?" 다음 3초를 반드시 침묵한다. 바로 답하면 효과가 사라진다. 수강생 표정이 "어…?"가 될 때까지 기다렸다가 이어간다.
💬 이어서 (10차 연결)
앱이 알아서 한 겁니다. 첫 줄이 제목이 되는 것도, 휴지통이 30일 뒤에 비워지는 것도 — 전부 아무도 안 시킨 일이에요. 10차 들으신 분들, 기억나세요? "왜 이렇게 느려요?" 하던 그 프로그램 — 그 느린 게 사실 사양이었죠. 같은 종류의 눈입니다. 안 보이는 동작을 보는 눈.
→ 넘어가며: "세 번째 칸은 제일 만만해 보이는데 — 함정이 있습니다."

08Part 2 · ③ 화면
③ 화면 — 어떻게 보이나 · 안 가본 화면도 화면
⏱ 6분 (33–39)
★ KEY POINT
화면은 세는 것부터 — 첫 화면 · 전환 지점 · 안 가본 화면. 안 가봤다고 없는 게 아니다.
🖥 화면
3항목(첫 화면 / 전환 지점 / 안 가본 화면도 화면) + 30초 퀴즈(메모앱 화면 몇 개?).
💬 이렇게 말하세요
화면 칸은 제일 쉬워 보이죠 — 맨날 보는 거니까. 그런데 함정이 있습니다. 화면은 '세는 것'부터예요. 첫째, 첫 화면 — 앱을 열면 제일 먼저 뭐가 보이나. 둘째, 전환 지점 — 어딜 누르면 화면이 바뀌나. 셋째가 함정인데 — 안 가본 화면도 화면입니다. 설정 화면, 휴지통 화면, 검색 결과 화면. 안 가봤다고 없는 게 아니에요. 30초 퀴즈 — 메모앱, 화면이 몇 개일까요? 휴지통은 세셨나요?
💡 강사 팁
답(목록·작성/보기·폴더·휴지통 = 4개 안팎)은 정확한 숫자보다 "휴지통을 셌는가"가 포인트. 시간이 밀렸으면 이 슬라이드를 4분으로 줄인다 — 퀴즈를 손들기로만.
→ 넘어가며: "자 — 마지막 칸. 오늘의 승부처입니다."

09Part 2 · ④ 연결 ⭐ 승부처
④ 연결 — 밖과 어떻게 닿나
⏱ 5분 (39–44)
★ KEY POINT
연결은 사람이 늘거나 기기가 늘 때 생기는 칸 — 판별 질문은 "혼자 쓰면 없어도 되는 기능은?"
🖥 화면
"혼자·폰 하나면(칸이 빈다) / 사람·기기가 늘면(로그인·동기화·공유·알림)" 대비.
💬 이렇게 말하세요
마지막 칸, 연결. 질문은 이겁니다 — 이 앱을 나 혼자, 폰 하나로만 쓴다면 없어도 되는 기능이 뭔가? 로그인 — 혼자면 필요 없죠. 공유 — 받을 사람이 없죠. 알림 — 나한테 뭘 알려요. 동기화 — 기기가 하나인데요. 이것들이 전부 연결 칸입니다. 사람이 늘거나, 기기가 늘 때 생기는 칸이에요. 그리고 이 칸이 왜 승부처냐 — 눈에 안 보이거든요. 이따가 여러분이 직접 그려보면 알게 됩니다.
💡 강사 팁 — 미리 예고해둔다

★ KEY POINT

💬 이렇게 말하세요 (시작 멘트)
이제 같이 하나 그려봅시다. 메모앱입니다. 제가 채우는 게 아니에요 — 저는 질문만 하고, 답은 여러분이 합니다. 그리고 오늘 훔쳐 가실 건 답이 아니라 질문입니다. 이따가 내 것을 그릴 때, 집에서 혼자 그릴 때 — 지금 제가 던지는 질문들을 그대로 자기한테 던지면 됩니다. 자, 첫 칸. 메모앱을 껐다 켜도 남아 있어야 하는 게 뭐죠?
📌 발문 시나리오 (상세 표는 03_정답지 §A)
① 데이터 — "껐다 켜도 남아야 하는 건?" 막히면: "지운 메모는 어디 가죠?" · "정렬 바꿔두면 유지되죠 — 어느 칸이에요?" ② 동작 — "버튼으로 시키는 일은?" → "아무도 안 눌렀는데 일어나는 일은?" (07의 저장 버튼 질문 회수) ③ 화면 — "모두 몇 개죠? 같이 세봅시다" → "휴지통 세셨어요?" ④ 연결 — "나 혼자만 쓰면 필요 없는 건?" ⑤ 자르기 — 이것만 강사가 직접 시연: "그림 그리기 기능도 넣을까요? … 3주 안에 되겠어요? 자르죠."
💡 운영 3규칙
① 답을 말하지 않는다 — 막히면 답 대신 더 작은 질문으로 쪼갠다. ② 틀린 답도 일단 적는다 — "이거 어느 칸이지?"를 되물어 수강생이 옮기게 한다. 이 이동이 최고의 학습 순간. ③ 질문 뒤 3초는 기다린다 — 침묵을 강사가 먼저 못 견디면 문답이 강의로 퇴화한다.
⚠️ 주의
완성된 4칸을 먼저 띄우지 말 것. 정답지(03)는 강사 머릿속 커닝페이퍼다. 그리고 답이 안 나온다고 강사가 채우기 시작하면 그냥 시범 강의가 된다 — 힌트 질문을 한 단계 더 쪼개는 게 맞는 대응이다.
→ 넘어가며: "같이 했으니 이제 조별로 — 이번엔 질문도 여러분이 던집니다."
