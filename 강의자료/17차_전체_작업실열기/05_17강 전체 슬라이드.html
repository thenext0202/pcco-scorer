서버 없이 주소가 생기는 무대 — 9차 5요소 중 넷이 돌아오고, 하나만 없다
몸
내 폴더(3단계)

기억
GitHub 저장소

무대 ⭐
아이디.github.io/
내-캘린더
서버 없이 · 돈 없이 · 따로 붙일 것 없이 주소
맥박
push → 1~3분 → 주소가 바뀜
오늘 여러 번 겪는다 — 9차 "push가 곧 배포"
창고 — 오늘은 없음
없음
데이터는 주머니(localStorage)에만 — "폰에서 열면 일정이 없다" → 다음 강의
🖥 강사 주소 하나를 폰으로 3초만 열어 보입니다 — 시연이 아닙니다. "이게 오늘 여러분 손에 생기는 것" 한 마디면 됩니다.
왜 github.io인가 — 서버 없이, 돈 없이, 따로 붙일 것 없이 주소가 생기는 유일한 무대. push 한 번이면 주소가 살고, 고쳐서 push하면 주소에서 바뀝니다(맥박). 창고만 없어서 — 오늘 적은 일정은 내 폰 주머니에만 남습니다.

작업실은 폴더 3단계입니다 — 12차 지도 3층 회수 · 이름과 개수는 각자
예시일 뿐 — 이름·개수는 각자 내-캘린더/ ← 1 루트 · 지형 ├─ index.html ├─ manifest.json ← PWA 서류 (④에서) ├─ sw.js ← PWA 서류 (④에서) ├─ CLAUDE.md ← 권장 ├─ css/ ← 2 폴더 · 골목 │ └─ style.css ← 3 파일 · 문패 ├─ js/ │ └─ app.js └─ icons/ └─ icon-192.png
1루트 · 지형
주소가 가리키는 곳. PWA 서류(manifest·sw)는 여기 — 다른 데 두면 폰이 앱으로 안 알아봅니다
2폴더 · 골목
옷·움직임·그림을 가른다 — 14차 "옷 바꾸다 뼈 부러지지 않게". data/ 등은 자유
3파일 · 문패
이름·개수 자유. 한 파일에 한 역할
3단계면 충분하고, 3단계는 있어야 한다 — 한 폴더에 다 쏟으면 AI가 다음 과업에서 엉뚱한 파일을 건드립니다.
