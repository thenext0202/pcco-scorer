## §A. 강사 작업실 CLAUDE.md 전문 (데모용 — 04 템플릿의 빈칸 4개를 채운 것)

슬라이드 07 데모 전에 `강사-캘린더/` 폴더에 아래를 `CLAUDE.md`로 저장하고 과업 1 → 파일 3개 → 브라우저 → push → 주소까지 **3회 리허설**. 데모는 빈 폴더에서 다시 하되 2분 넘으면 완성본 주소로 전환.

```markdown
# 강의 기획 작업실

## 정체성
이 폴더의 개발 담당. 작게, 한 번에 한 가지씩. 시키지 않은 기능은 만들지 않는다. 주인은 정금구.

## 임무
월 보기 업무 달력 하나를 만들고 고친다. 주 보기·알림·외부 연동·설정 화면은 임무 밖 — 요청받아도 "임무 밖"이라고 답하고 만들지 않는다.

## 규칙
### 주소에서 돌아가기 위해 (github.io)
1. 파일 경로는 전부 상대 경로. 외부 CDN·빌드 도구·패키지 설치 금지.
2. 파일은 이 폴더 안 `index.html` · `style.css` · `app.js` 세 개만. 새 파일을 만들려면 먼저 묻는다.
3. 데이터 저장은 브라우저 저장(localStorage) 하나. 서버·DB 없음.
### 사용감 (UX)
4. 폰 세로 화면(390px)에서 먼저 보기 좋게. 7열이 가로 스크롤 없이 다 보여야 한다. PC는 그 다음.
5. 누르는 것은 전부 44px 이상.
6. (③에서 추가) 일정이 없는 달에는 그리드 아래에 "이번 달 일정이 없습니다 — 날짜를 눌러 추가하세요" 한 줄.
### 작업
7. 한 과업에 한 가지만 바꾼다. "그것만"이라고 하면 다른 파일·다른 기능은 건드리지 않는다.
8. 합격 기준 3 — ① 이번 달 그리드 + 오늘 표시 ② 일정 추가·삭제, 새로고침해도 남음 ③ 종류별 색. 셋이 되면 멈춘다.

## 구조 (구조도)
- `index.html` 뼈대 — 상단(월 이름, ◀ ▶, 오늘 버튼) / 달력 그리드 / 일정 입력 폼 / 선택한 날의 일정 목록
- `style.css` 옷 — 색·크기·간격만
- `app.js` 움직임 — 달 계산·저장·그리기

## 화면 (화면도)
- 부품 3: 날짜 칸(반복) · 일정 입력 폼 · 일정 목록
- 상태 4: 일정 없는 달 · 저장 중/저장됨 · 추가됨 · 잘못 입력(제목 없음·날짜 없음)
- 이동 2: ◀ ▶ 달 넘기기 · 「오늘」 버튼으로 돌아오기

## 데이터 (데이터도)
- 표 「일정」: 번호 · 날짜 · 제목 · 종류(허용목록) · 메모(선택) · 만든 시각
- 표 「종류」: 이름 · 색 — 허용목록: 강의=초록 · 기획=파랑 · 마감=빨강 · 미팅=보라 · 촬영=주황
- 줄 1: 일정.종류 → 종류.이름. 목록에 없는 종류는 저장 거부.
- 기준: 오늘 = 기기 날짜. 1일의 요일과 그 달의 일수를 정확히.

## 출력
끝나면 두 줄만: (1) 바꾼 파일 이름 (2) 브라우저에서 확인하는 법. 코드 설명·요약 금지.
```

**데모 멘트(슬라이드 07, 3분)**: "이 폴더엔 지금 CLAUDE.md 한 장뿐입니다. 헤더만 보세요 — 정체성·임무·규칙·구조·화면·데이터·출력. (claude 실행) 과업은 한 줄입니다. (과업 1 붙여넣기) … 파일이 세 개 생겼죠. index.html을 열면 — 이번 달, 오늘이 표시돼 있습니다. 요청은 한 줄이었습니다. 차이는 미리 써둔 한 장이에요. 15차에 지침을 쓰신 분들은 이게 그 지침입니다. 설계도 세 장 그리신 분들은 구조·화면·데이터 절이 그 세 장입니다." (폰으로 강사 주소를 열어 보이며) "이게 push 한 번 뒤의 모습입니다. 오늘 여러분도 이 주소를 들고 나갑니다."

**규칙 6은 데모 폴더에만 미리 넣어 둔다** (완성본에서 상태가 하나 보이게). 수강생 템플릿엔 `6. (③에서 추가) ___` 빈칸.

| 관찰(기록표에 적힌 것) | 패턴 | 형용사 규칙 (X) | 측정 가능한 규칙 (O) |
|---|---|---|---|
| "넣었는데 들어갔는지 모르겠다" | 확인 불가 | 저장을 알기 쉽게 | 추가·삭제 뒤 상단에 '저장됨' 띠 1초 |

| "다음 달 갔다가 못 돌아옴" | 헤맴 | 오늘로 쉽게 | 상단에 '오늘' 버튼 고정, 어느 달에서든 1탭 |

| "지웠는데 지워진 건지" | 확인 불가 | 삭제 피드백 | 삭제 뒤 목록에서 사라지며 '삭제됨' 1초 |
| "종류 고르는 칸을 못 봄" | 헤맴 | 종류를 보이게 | 종류는 글자 목록이 아니라 색 칩 5개, 기본 선택 1개 |
| "폰에서 토요일이 잘림" | (원칙 ④) | 폰에서 잘 보이게 | 7열 각 칸 최소 44px, 숫자 13px, 칸 안 줄바꿈 금지 |
| "오늘이 어딘지 1초 넘게 찾음" | 멈칫 | 오늘 강조 | 오늘 칸은 테두리 2px + 숫자 굵게 + 상단에 '10월 1일 (목)' 표기 |
| "탭을 5번 했다" (과업 ①) | 탭 수 | 간단하게 | 일정 추가는 날짜 탭 → 제목 입력 → 저장, 3탭 이내 |

순회 한마디: "'알기 쉽게'를 숫자로 하면요?" / "몇 초? 몇 px? 몇 탭?" / "그 한 줄만 추가하고 '그것만 반영해'."

## §E. FAQ (슬라이드 25 + 질의응답)

|---|---|
| Claude Code 말고 claude.ai로도 되나요? | ①②는 됩니다(13차 방식 — CLAUDE.md 전문 + 과업 1을 붙여 Artifacts로). 주소는 GitHub가 있어야 합니다. 그래서 세팅 가이드가 먼저였고, 막히면 3단계로 풉니다. |
| 내 앱으로 하면 안 되나요? (중급) | 오늘은 제가 전원의 달력을 같은 과업으로 열어 봐야 해서 뼈대가 같아야 합니다. 내 앱은 선택 과제 ⑥ — 내 3종 세트를 변환표대로 CLAUDE.md로 접고 오늘 순서 그대로. |
| 왜 폰에서 열면 일정이 없나요? | 주머니(브라우저 저장)에만 남겼으니까요 — 16차 세 곳 중 창고를 비워 뒀습니다. 주소는 공유됐는데 데이터는 공유되지 않은 것. 다음 강의입니다. |
| 홈 화면에 설치하면 안 되나요? | 됩니다(7차). 오늘 뺀 이유는 서비스워커 캐시가 '고치고 push하면 바뀐다'를 가려서 — 9차와 같은 이유. 선택 과제 ④. |
| 저장소를 private으로 하면? | 무료 Pages가 안 됩니다. 과업 2에 "공개"가 들어 있는 이유. 달력에 민감한 일정은 넣지 마세요(가명·자리표시). |
| Claude Code가 파일을 더 만들었어요 | 규칙 2(먼저 묻는다)·7(그것만)을 어긴 것. CLAUDE.md를 고치지 말고 "규칙 2를 어겼어. 파일 3개로" 한 줄. |
| 날짜가 틀려요 (1일 요일) | 합격 기준 ①이 안 된 것. "합격 기준 ①이 안 돼. 이번 달 1일 요일을 확인해" 한 줄. 오늘 날짜(2026-10-01 목)로 바로 확인. |
| UI를 한 번 더 바꾸고 싶어요 | 오늘은 한 문장 한 번. 두 번째는 선택 과제. "색은 취향, 멈칫은 규칙." |
| 손님 테스트 기록이 전부 '없음'이에요 | 주인 모드로 한 겁니다 — "화면이 알려줬나요, 아셨나요?" 아는 길로 간 자리를 다시. 즉석 점검·가족 테스트(선택 ②)가 잡아 줍니다. |
| 다음 강의는 언제, 뭐예요? | 날짜는 공란. 주제는 "창고 연결" — 오늘 비워 둔 창고. 일정 없이 한 장(슬라이드 23). "종료·수료"라는 말은 쓰지 않는다. |
| SQL은요? | 16차 답 그대로 — 다음 시즌. 오늘은 창고 자체를 비웠다. |
