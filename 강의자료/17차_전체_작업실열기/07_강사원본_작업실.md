## §A. 순회 질문 묶음 — 단계별 (러닝시트와 같은 문구)

| 단계 | 묻는 것 | 답 못 하면 |
|---|---|---|
| ① 작업실 | "폴더 몇 단계예요?" / "`claude` 떴어요? `gh auth status`는요?" | 3단계(복사→세 줄→한 단계) 먼저, 3분 → 창구 |
| ② 설계 | "**핵심 과업이 뭐예요?**" / "빈 달엔 뭐가 보여요?" / "다음 달 갔다가 어떻게 돌아와요?" | 02 카드로 되돌린다 — 답 없이 만들기 시작한 사람은 막지 않는다(그 결과가 강의 2의 증명) |
| ② 주소 | "주소 떴어요? 폰으로 열어 봤어요?" | 사람이 직접 하는 2가지 확인(로그인 / Pages 클릭) |
| ③ 손님 | "**몇 탭이었어요?**" / "어디서 멈칫?" / "됐는지 화면이 말했어요?" / "고친 거 push했어요?" | 기록이 전부 "없음" → "화면이 알려줬나요, 아셨나요?" |
| ③ 시키기 | "뭐라고 시켰어요?" | 형용사("알기 쉽게")면 → "숫자로 하면요? 몇 초, 몇 px, 몇 탭?" / 여러 개 한 번에 → "한 가지만, 그것만" |
| ③ UI | "그건 생김새예요, 겪는 거예요?" | "색은 취향, 멈칫은 설계" — 손님 기록부터 |
| ④ 설치 | "홈 화면에 떴어요?" / "설치하고 또 고쳤어요?" | 캐시 — 참고 카드 B ③. 다음부턴 고치고 나서 설치 |
| 범위 | "쓰는 사람이 한 명이에요, 팀이에요?" | 팀 공유·알림·구글 연동 → "창고가 필요한 일 — 다음 강의" |

**말하지 않는 것**: "이렇게 만드세요" / "그건 틀렸어요" / 코드 설명. 대신 "빠뜨리면 이렇게 돼요"까지만.

## §B. 첫 실행 전형적 누락 패턴 (② 손들기 · ③ 순회용)

설계 카드 없이(또는 ③④ 비워 두고) Claude Code에게 캘린더를 시키면 보통 이렇게 나온다. "상태 4칸 다 있는 사람?" 손들기가 ≈0인 근거.

| 질문 번호 | 첫 실행에서 | 수강생 관찰 | 고치는 문장 예 |
|---|---|---|---|
| ③ 비어 있을 때 | **거의 항상 없음** — 빈 그리드만 | "빈 달인데 아무 말이 없다" | "일정 없는 날/달엔 '오늘 일정 없음 — 눌러서 추가' 한 줄만 추가해" |
| ③ 됐을 때 | 절반 — 체크는 되는데 표시가 약함 | "체크했는지 모르겠어서 두 번 눌렀다" | "체크하면 1초 초록 띠, 그것만" |
| ③ 안 됐을 때 | 거의 없음 — 제목 없이 저장되거나 조용히 무시 | "빈 제목으로 눌렀는데 아무 일도" | "제목 없이 저장 금지, 입력칸 아래 빨간 이유 한 줄" |
| ③ 기다릴 때 | 로컬이라 거의 즉시 — 해당 없음이 정답 | — | (없어도 됨 — "기다림이 없으면 없는 거예요") |
| ④ 돌아오는 길 | 절반 — 오늘 버튼이 있거나 없거나 | "다음 달 갔다가 못 돌아왔다" | "상단에 '오늘' 버튼 고정, 어느 달에서든 1탭" |
| ② 핵심 과업 | 모든 기능이 같은 크기 → 체크가 3~4탭 | "체크 하나에 네 번 눌렀다" | "오늘 일정 체크는 날짜 탭 없이 목록에서 바로, 1탭" |
| ⑤ 폰 | 대체로 됨(규칙 넣은 사람) / 안 넣으면 7열이 넘침 | "토요일이 잘린다" | "폰 세로 390px에서 7열이 가로 스크롤 없이, 체크박스 44px" |
| 날짜 계산 | 가끔 1일 요일·31일·달 넘기기 오류 | 손님 테스트에서 걸림 | "이번 달 1일 요일을 확인해" |
| 폴더 | 3단계 안 시키면 루트에 전부 | — | "파일을 css/·js/·icons/ 폴더로 나눠, 내용은 그대로" |

## §C. 막힘·해결 기록 + 제출 링크 확인 체크리스트

| 시각 | 단계 | 막힌 곳(에러 한 줄) | 3단계로 풀렸나 | 창구에서 한 것 | 08 §4에 넣을 키워드 |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

같은 막힘 3명 이상 → 강사 화면에 띄워 다같이 3단계 1회(3분). ★ 표시.
**사람이 직접 해야 하는 2가지**(미리 아는 것): (a) `gh auth login` 브라우저 로그인 (b) 저장소 Settings → Pages → main / root → Save.

### C-2. 제출 링크 확인 체크리스트 (클로징 즉석 점검 + 수업 후 전수)

슬랙으로 받은 것(주소 · 고친 것 한 줄 · 캡처)마다:

| # | 확인 | O/X | 회신 재료 |
|---|---|---|---|
| 1 | 주소가 열린다 (1~3분 지연 감안) | | 안 열리면 "Pages 켜졌나요? 설정 → Pages" |
| 2 | 이번 달·오늘이 표시된다 (1일 요일 맞나) | | |
| 3 | 일정 넣고 체크 → 새로고침 → 남아 있나 | | |
| 4 | 폰에서 7열 가로 스크롤 없이 (강사 폰) | | |
| 5 | **그 사람의 핵심 과업**(제출 메시지나 화면에서 추정) — 탭 수 · 멈칫 (강사가 손님 모드로) | | 즉석 점검에서 소리 내어 센 것 |
| 6 | 상태 4칸 중 몇 칸 보이나 (빈 날 안내 / 됐을 때 / 안 됐을 때) | | "비어 있을 때 한 줄만 더" |
| 7 | 돌아오는 길(오늘 버튼) 있나 | | |
| 8 | 고친 것 한 줄이 실제로 반영돼 있나 | | push 안 됐으면 "push해" |
| 9 | 설치했으면 — manifest·아이콘이 뜨나 (홈 화면 캡처) | | |

**즉석 점검 형식(슬라이드 17)**: 제출 3개(지원자 우선) · 강사 폰 미러링 · **그 사람의 핵심 과업**을 손님 모드로 · "___에서 멈칫 → 어떻게 고쳤나 → 잡혔나?" · 칭찬 1 · 보완 1 · UI는 한 마디("색은 취향, 멈칫은 설계"). 7분.

**수업 후 회신 틀(슬랙, 3일 내)**: "주소 열림 ✅ / 핵심 과업 __탭, 멈칫: ___ / 상태 __칸 / 고친 '___' 반영 ✅ / 다음 바퀴 추천: 선택 과제 ○번"

## §D. 관찰 → 고칠 것 → 시키는 문장 예 10 (③ 순회 — 형용사를 숫자로)

| 손님 기록 | 패턴 | 형용사로 시킴 (X) | 한 가지만, 측정 가능하게 (O) |
|---|---|---|---|
| "체크했는지 모르겠다" | 확인 불가 | 체크를 알기 쉽게 | "체크하면 그 줄에 1초 초록 띠. 그것만" |
| "빈 달에서 멈칫" | 멈칫 | 빈 화면 친절하게 | "일정 없는 달엔 그리드 아래 '이번 달 일정 없음 — 날짜를 눌러 추가' 한 줄" |
| "다음 달 갔다가 못 돌아옴" | 헤맴 | 오늘로 쉽게 | "상단에 '오늘' 버튼 고정. 어느 달에서든 1탭" |
| "추가 버튼 찾느라 헤맴" | 헤맴 | 추가를 눈에 띄게 | "날짜를 누르면 그 날짜가 들어간 입력칸이 바로 열리게. 2탭 이내" |
| "제목 비우고 눌렀는데 조용함" | 확인 불가 | 입력 검사 | "제목 없이 저장 금지, 입력칸 아래 빨간 이유 한 줄" |
| "체크 하나에 4탭" | 핵심 과업 | 간단하게 | "오늘 할 일 목록을 첫 화면에, 체크는 목록에서 바로 1탭" |
| "종류 고르는 칸 못 봄" | 헤맴 | 종류를 보이게 | "종류는 글자 목록 말고 색 칩 4개, 기본 선택 1개" |
| "토요일이 잘림" | ⑤ 폰 | 폰에서 잘 보이게 | "7열 각 칸 최소 44px, 숫자 13px, 칸 안 줄바꿈 금지" |
| "오늘이 어딘지 찾음" | 멈칫 | 오늘 강조 | "오늘 칸 테두리 2px + 숫자 굵게 + 상단에 '10월 2일 (금)'" |
| "지웠는지 모르겠다" | 확인 불가 | 삭제 피드백 | "삭제하면 그 줄이 사라지며 상단에 '삭제됨' 1초" |

순회 한마디: "몇 초? 몇 px? 몇 탭?" / "그것만 — 다른 건 건드리지 마, 붙이셨어요?" / "push하고 폰 새로고침 했어요?"

## §E. FAQ (슬라이드 20 + 질의응답)

| 질문 | 답 |
|---|---|
| claude.ai로도 되나요? | 됩니다 — 설계 카드 다섯 답 + "단일 HTML 캘린더"를 붙이면 Artifacts로 화면까지. 주소는 GitHub가 있어야 하고요. 그래서 세팅 가이드가 먼저였고, 막히면 3단계로 풉니다. |
| 주 보기로 해도 되나요? / 체크를 다르게 해도? | 됩니다. 질문 5에 답만 있으면 뭐든. 오늘 소재는 "업무 일정을 적고 체크한다" 하나고 나머지는 전부 설계입니다. |
| CLAUDE.md 꼭 써야 하나요? | 아니요, 권장입니다. 쓰면 매 과업마다 "폰 먼저, 3단계, 그것만"을 다시 안 말해도 돼요. 참고 카드 A 예시를 복사해 `## 화면`만 내 답으로 바꾸면 끝. |
| 왜 폴더를 3단계로? | 한 폴더에 다 쏟으면 다음 과업에서 AI가 엉뚱한 파일을 건드립니다. 12차 지도 3층 — 지형·골목·문패 — 의 실물이에요. 이름·개수는 자유. |
| 팀이랑 공유하고 싶어요 / 알림 / 구글 캘린더 연동 | 창고가 필요한 일입니다 — 다음 강의. 오늘은 쓰는 사람 한 명(질문 ①)으로. |
| 왜 폰에서 열면 일정이 없나요? | 주머니(브라우저 저장)에만 남겼으니까요 — 16차 세 곳 중 창고를 비워 뒀습니다. 주소는 공유됐는데 데이터는 공유되지 않은 것. 다음 강의. |
| 설치했는데 고친 게 안 보여요 | 캐시 — 서비스워커가 옛 화면을 들고 있어요. 그래서 설치는 마지막이라고 했습니다. 앱 지우고 다시 설치하거나, 브라우저로 열어 새로고침. |
| 저장소를 private으로 하면? | 무료 Pages가 안 됩니다. 달력에 민감한 일정은 가명으로. |
| Claude Code가 파일을 루트에 다 만들었어요 | "파일을 css/·js/·icons/로 나눠, 내용은 그대로" 한 줄. (CLAUDE.md에 3단계 규칙이 있으면 안 생기는 일.) |
| 손님 기록이 전부 '없음'이에요 | 주인 모드로 한 겁니다 — 화면이 알려줬나요, 아셨나요? 아는 길로 간 자리를 다시 보세요. 그래도 안 보이면 즉석 점검·가족 테스트(선택 ②)가 잡아 줍니다. |
| 다음 강의는? | 날짜 공란. 주제는 "창고 연결". "종료·수료"라는 말은 쓰지 않는다. |
