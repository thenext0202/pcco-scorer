# 참고 카드 A — 작업실 (참고용 · 이름·개수는 자유)

> 17차 「내 캘린더를 주소로」 · 이 카드는 **예시**입니다. 폴더 이름도 파일 개수도 CLAUDE.md도 — 쓰든 안 쓰든 자유. "이렇게 하세요"가 아니라 "빠뜨리면 이렇게 됩니다"만 적었습니다.

## ① 폴더 3단계 — 예시 트리

```
내-캘린더/                      ← 1 루트 (12차: 지형) — 주소가 가리키는 곳
  index.html                    화면 한 장
  manifest.json                 앱 정보 — 이름·아이콘·색 (실습 ④에서 생김)
  sw.js                         오프라인·캐시 (실습 ④에서 생김)
  CLAUDE.md                     지침 한 장 (권장 — 아래 ②)
  css/                          ← 2 폴더 (골목) — 옷
    style.css
  js/                           ← 2 폴더 (골목) — 움직임
    app.js
  icons/                        ← 2 폴더 (골목) — 그림
    icon-192.png · icon-512.png ← 3 파일 (문패) — 한 파일에 한 역할
```

**왜 3단계** — 한 폴더에 다 쏟으면 AI가 다음 과업에서 엉뚱한 파일을 건드린다. 3단계면 충분하고, 3단계는 있어야 한다.
12차 지도 3층 그대로 — 지형(루트) · 골목(폴더) · 문패(파일). `data/` 같은 폴더를 더 두는 것도, 이름을 바꾸는 것도 자유.

## ② CLAUDE.md 예시 — 권장

폴더에 이 한 장을 써두면 매 과업마다 다시 말하지 않아도 됩니다(15차 지침의 Claude Code판). **안 써도 됩니다.** 쓰는 사람은 `___` 와 `## 화면` 절만 내 것으로 — 설계 카드 질문 5의 답을 거기에 옮기면 그게 곧 지침입니다. 복사용 전문은 `CLAUDE.md_예시.txt`.

```markdown
# ___ 작업실

## 정체성
- 이 폴더의 개발 담당. 작게, 한 번에 하나씩 만든다.

## 임무
- 업무용 일정체크 캘린더 하나. 일정을 적고 체크한다. 시키지 않은 기능은 만들지 않는다.

## 규칙
- 파일 경로는 상대 경로. 외부 CDN 금지 — 주소 하나로 혼자 돌아가야 한다.
- 폴더 3단계 유지: 루트(index.html · manifest.json · sw.js) → css/ · js/ · icons/ → 파일. 새 파일은 맞는 폴더에.
- 폰 세로 화면 먼저. 누르는 것은 44px 이상.
- 한 과업에 한 가지만. "그것만"이라고 하면 다른 파일·다른 기능은 건드리지 않는다.
- 저장은 브라우저 저장(localStorage). 서버·로그인·외부 서비스 없음.

## 구조
- 내-캘린더/ → index.html · manifest.json · sw.js · CLAUDE.md
- css/ → style.css
- js/ → app.js
- icons/ → icon-192.png · icon-512.png

## 화면  ← 설계 카드 질문 5의 답을 여기에
- 쓰는 사람: ___ (누가 · 하루 몇 번 · 폰/PC)
- 핵심 과업: ___ (가장 자주 하는 일 — 2탭 안에)
- 상태 4칸: 비어 있을 때 ___ / 기다릴 때 ___ / 됐을 때 ___ / 안 됐을 때 ___
- 이동: ___ 에서 ___ 로. 오늘로 돌아오는 길: ___
- 폰 먼저: 엄지로 되나 · 누르는 건 44px

## 데이터
- 일정 하나 = 날짜 · 제목 · 종류 · 체크 여부
- 주머니(localStorage)에 저장. 지우기 전까지 이 브라우저에만 남는다.

## 출력
- 과업이 끝나면: 바꾼 파일 목록 + 내가 확인하는 방법 두 줄.
- 코드 설명은 하지 않는다.
```
