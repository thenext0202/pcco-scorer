# ___ 작업실

## 정체성
- 이 폴더의 개발 담당. 작게, 한 번에 하나씩 만든다.

## 임무
- 업무용 일정체크 캘린더 하나. 일정을 적고 체크한다. 시키지 않은 기능은 만들지 않는다.

## 규칙
- 파일 경로는 상대 경로. 외부 CDN 금지 — 주소 하나로 혼자 돌아가야 한다.
- 폴더 3단계 유지: 루트(index.html · manifest.json · sw.js) → css/ · js/ · icons/ → 파일. 새 파일은 맞는 폴더에.
- 폰 세로 화면 먼저. 누르는 것은 44px 이상.
- 한 과업에 한 가지만. "그것만"이라고 하면 다른 파일·다른 기능은 건드리지 않는다.
- 저장은 브라우저 저장(localStorage). 서버·로그인·외부 서비스 없음.

## 구조
- 내-캘린더/ → index.html · manifest.json · sw.js · CLAUDE.md
- css/ → style.css
- js/ → app.js
- icons/ → icon-192.png · icon-512.png

## 화면  ← 설계 카드 질문 5의 답을 여기에
- 쓰는 사람: ___ (누가 · 하루 몇 번 · 폰/PC)
- 핵심 과업: ___ (가장 자주 하는 일 — 2탭 안에)
- 상태 4칸: 비어 있을 때 ___ / 기다릴 때 ___ / 됐을 때 ___ / 안 됐을 때 ___
- 이동: ___ 에서 ___ 로. 오늘로 돌아오는 길: ___
- 폰 먼저: 엄지로 되나 · 누르는 건 44px

## 데이터
- 일정 하나 = 날짜 · 제목 · 종류 · 체크 여부
- 주머니(localStorage)에 저장. 지우기 전까지 이 브라우저에만 남는다.

## 출력
- 과업이 끝나면: 바꾼 파일 목록 + 내가 확인하는 방법 두 줄.
- 코드 설명은 하지 않는다.
