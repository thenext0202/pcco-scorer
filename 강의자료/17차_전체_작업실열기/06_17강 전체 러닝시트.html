04강의 1 · 왜 github.io인가 ⭐
서버 없이 주소가 생기는 무대 — 9차 5요소 중 넷이 돌아오고, 하나만 없다

9차에 앱의 다섯 요소를 배웠죠 — 몸, 기억, 무대, 맥박, 창고. 오늘 그중 넷이 돌아옵니다. 몸은 내 폴더예요, 12차 말로 "파일에는 자리가 있다". 기억은 GitHub 저장소 — 노트북을 바꿔도 남아요, 그래서 앞으로 매 강의가 여기서 시작합니다. 무대가 오늘의 주인공인데, 아이디 점 github.io 슬래시 내 캘린더 — 서버 없이, 돈 없이, 따로 뭘 붙이지 않고 주소가 생깁니다. 이게 되는 곳이 사실상 여기뿐이에요. 맥박은 push 하면 1~3분 뒤에 주소에서 바뀌는 것 — 오늘 여러 번 겪으실 겁니다. 그리고 창고. 오늘은 없어요. 적은 일정은 내 폰 주머니에만 남습니다. 왜 그게 문제인지는 수업 끝에 직접 보시게 될 거예요. 제 걸로 하나 보여드릴게요 — (폰으로 주소 열고) — 이게 오늘 여러분 손에 생기는 겁니다. 이 정도면 됐어요.
