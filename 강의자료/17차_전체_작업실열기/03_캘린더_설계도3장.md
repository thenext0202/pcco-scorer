## 1쪽 — 17차 · 캘린더 설계도 ① 구조도 (12차 양식 · 완성 견본 — 읽기용)

**작성 순서**: ① 한 문장 읽기 → ② 트리에서 파일 3개의 자리와 "왜" 읽기 → ③ 루트 파일 체크 확인 → 끝. (쓰지 않습니다)

**① 이 앱 — 한 문장** (누가 · 무엇을 하면 · 무엇이 남는가):
> **내가** 날짜를 고르고 일정을 넣으면 **내 업무 종류 색으로 달력에 표시되고**, 새로고침해도 **남는다**.

**② 쏟아내기 → ③ 묶기**: 이번 달 그리드 · 오늘 표시 · 달 넘기기 · 오늘로 돌아오기 · 일정 넣기 · 일정 지우기 · 종류별 색 · 껐다 켜도 남기 → **보이는 것** = 뼈대(index.html) + 옷(style.css) / **계산·저장·그리기** = 움직임(app.js) / **남는 것** = 브라우저 저장(주머니)

**④ 트리** — 파일마다 "왜" 한 줄 + 태그 ([화] 화면 · [동] 동작 · [데] 데이터):

```
내-캘린더/
├─ CLAUDE.md      왜: AI용 문패 — 지침 한 장 (설계도 세 장이 세 절로 접힘)       [문패]
├─ index.html     왜: 뼈대 — 상단(월 이름·◀ ▶·오늘 버튼) / 달력 그리드 /
│                      일정 입력 폼 / 선택한 날의 일정 목록                          [화]
├─ style.css      왜: 옷 — 색·크기·간격만 (분위기·주색은 여기서 바뀜)               [화]
└─ app.js         왜: 움직임 — 달 계산 · 저장(브라우저) · 그리기                      [동][데]
    (창고 자리)   왜: 비워 둠 — 오늘 데이터는 주머니(브라우저 저장). 창고는 다음 강의   ★
```

**파일 3개 = 14차 삼형제** (오늘 유일한 '정체 공개' — 열어 보지 않습니다, 이름만 압니다):

| 파일 | 실명 | 한 줄 역할 | 오늘 누가 건드리나 |
|---|---|---|---|
| `index.html` | 뼈대 (HTML) | 무슨 상자들이 있나 — 상단·그리드·폼·목록 | 과업 1에서 Claude Code가 만든다 |
| `style.css` | 옷 (CSS) | 그 상자의 색·크기·자리 | 과업 4(UI 한 문장)에서만 바뀐다 |
| `app.js` | 움직임 (JavaScript) | 누르면 무엇이 일어나나 — 달 계산·저장·그리기 | 과업 3(규칙 한 줄)에서 바뀐다 |

**⑤ 루트에 둘 파일**: ☑ CLAUDE.md (AI용 문패 — 04 배포키트 템플릿) · ☐ README — 생략(강사가 주소로 본다) · ☐ 재료 목록 — 생략(규칙 1 "빌드 도구·패키지 금지") · ☐ .env — 생략(비밀 열쇠 없음) · ☐ .gitignore — 생략(숨길 것 없음). **비워도 되는 칸이 있다는 것도 설계.**

> ✅ 합격 기준과 대조: 최상위 3~6개? → 파일 3 + 문패 1 ✓ / 모든 파일에 "왜"? ✓ / 태그? ✓ / 보너스(안 만들 자리 = 창고)? ✓

## 2쪽 — 17차 · 캘린더 설계도 ② 화면도 (14차 양식 5단계 · 완성 견본 + 상태 4칸은 ②에서 채움)

## 3쪽 — 17차 · 캘린더 설계도 ③ 데이터도 (16차 양식 · 반완성 — 「종류」 표만 채움)

**작성 순서**: ①② 읽기 → **③ 「종류」 표 채우기 (실습 ①, 3분)** → ④ 줄 읽기 → ⑤ 문지기 표 읽기 → 종류 표를 CLAUDE.md `[종류 목록]` 빈칸에 옮겨 적기.

> 💡 **「종류」 표가 오늘 유일하게 각자 채우는 칸입니다.** 내 업무 종류 3~6개 + 색 이름(한글 — "짙은 초록"). 이것이 16차 **허용목록**의 실물 — 목록에 없는 종류는 저장이 거부됩니다.

**① 남길 것 고르기** — 화면도의 「보이는 데이터」에서: 날짜 · 제목 · 종류(색) · 메모 · 오늘
- 남는 것: 일정(날짜·제목·종류·메모·만든 시각) · 종류(이름·색)
- 흐르는 것: "저장됨" 1초 띠 · 지금 보고 있는 달 · 선택한 날 · 오늘(기기 날짜에서 매번 계산)

**② 표 이름 짓기** — 사실이 두 종류: "이런 일정이 있다" / "이런 종류는 이 색이다"

| 표 | 한 종류의 사실 | 한 줄 = |
|---|---|---|
| 일정 표 | 넣어 둔 일정 | "10월 7일에 '○○ 미팅'(미팅)을 넣었다" |
| 종류 표 | 내 업무 종류와 색 | "미팅은 파랑이다" |

**③ 열 적기 + ④ 줄 긋기**:

```
┌ 일정 표 (완성) ───────────────────────┐      ┌ 종류 표 (내가 채운다) ──────────────┐

│ 제목       글자 30자     필수          │  │   ├──────────────────────────────────┤
│ 종류 →     글자          허용목록 ─────┼──┘   │ (예) 미팅   ·  파랑        ← 예시, 지워도 됨 │
│ 메모       글자          선택          │      │ ________   ·  ________              │
│ 만든 시각  시각          안 적으면 지금 │      │ ________   ·  ________              │
└──────────────────────────────────────┘      │ ________   ·  ________              │
                                               │ ________   ·  ________              │
                                               │ ________   ·  ________              │
                                               └──────────────────────────────────────┘
```

**줄 1**: 일정.종류 → 종류.이름 — **목록에 없는 종류는 저장 거부** (허용목록)
**왜 갈랐나**: "미팅=파랑"을 일정마다 적으면 색을 바꿀 때 일정 수만큼 고쳐야 한다 → 종류는 종류 표에 한 번만, 일정은 이름으로 가리킨다.

**⑤ 문지기 표**:

| 표 | 읽기 | 쓰기 | 고치기 | 지우기 |
|---|---|---|---|---|
| 일정 표 · 종류 표 | **오늘은 주머니(브라우저 저장)라 문지기 없음 — 내 브라우저에만 남고, 남의 폰에서 열면 비어 있다. 창고(DB)는 다음 강의** | | | |

**비밀 열쇠**: 없음 (외부 AI·결제 안 씀 · 서버 없음)
