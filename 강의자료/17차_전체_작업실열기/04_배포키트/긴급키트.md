# 긴급키트 — 막혔을 때 보는 한 장 (17차 「작업실을 연다」)

> 순서: **① 막힘 해결 3단계 (3분)** → **② 세팅 창구 (3분)** → **③ 긴급 경로 A·B·C**. 창구에서도 LLM에게 먼저 묻습니다.
> "포기가 아니라 다음 수단" — 한 번에 한 단계.

---

## 1. 막힘 해결 3단계

| 단계 | 하는 것 | 하지 않는 것 |
|---|---|---|
| ① **복사** | 터미널의 빨간 줄(에러)을 **그대로** 복사 — 줄이면 안 됨 | "안 돼요"라고만 쓰기 · 에러를 요약하기 |
| ② **세 줄로 묻기** | `내 OS: Windows/Mac` / `하려던 것: gh로 저장소 만들기` / `에러: (붙여넣기)` + "**내가 직접 해야 하는 게 있으면 그것부터, 한 번에 한 단계만**" | 처음부터 다 설명하기 · 여러 질문 한 번에 |
| ③ **한 단계만** | 시키는 첫 단계만 하고 → 확인 명령 다시 → 안 되면 ①로 | 시키는 걸 다 한 번에 하기 · 안 됐는데 다음 단계 |

**어디에 묻나**: Claude Code 프롬프트 안에서 바로(가장 좋음). Claude Code가 안 뜨면 claude.ai 새 대화에.

### 묻는 문장 틀 — 복사해서 빈칸만 채우기

```
내 OS: ___
하려던 것: ___
에러: ___
내가 직접 해야 하는 게 있으면 그것부터, 한 번에 한 단계만.
```

### 3분 규칙
3단계로 **3분** 안에 안 풀리면 손 → 세팅 창구. 창구에서도 3분 — 그래도 안 되면 아래 긴급 경로.

---

## 2. 사람이 직접 해야 하는 2가지 (LLM이 대신 못 함 — 미리 알아 두기)

| | 어디서 | 하는 일 |
|---|---|---|
| (a) **브라우저 로그인** | 터미널 `gh auth login` → GitHub.com → HTTPS → "브라우저로 로그인" | 브라우저가 열리면 GitHub에 로그인하고 화면의 코드를 확인. 끝나면 터미널로 돌아와 Enter |
| (b) **Pages 켜기 클릭** | GitHub 저장소 페이지 → **Settings → Pages** | Branch를 **main / (root)** 로 고르고 **Save**. (Claude Code가 `gh api`로 켜 보고, 안 되면 이 두 번 클릭) |

이 둘을 빼면 나머지 막힘은 거의 3단계로 풀립니다.

---

## 3. 긴급 경로 A · B · C (3단계 3분 → 창구 3분 뒤에만)

| 막힌 곳 | 경로 | 할 수 있는 것 |
|---|---|---|
| **A. Claude Code 안 뜸** (설치·로그인 — 계정은 전원 있음) | 세팅 창구 3분(08 가이드 §1·§2 재수행) → 안 되면 **claude.ai 새 대화**에 CLAUDE.md 전문 + 과업 1을 붙여 Artifacts로(13차 방식, 단일 HTML) → html 다운로드 → 폴더에 | ①② 로컬까지 + ③ 고치기(같은 대화에서). push는 B |
| **B. GitHub·gh 안 됨** (인증·권한) | 세팅 창구 3분(`gh auth login` 재수행) → 안 되면 **강사 공용 저장소** `17-class`의 하위 폴더 `내이름/`에 파일 3개를 슬랙으로 보내 강사가 push → `강사주소/17-class/내이름/` | 주소 생김 → 손님 테스트·제출 가능. "다음 강의 전에 내 계정으로 옮기기"가 선택 과제 7 |
| **C. 노트북 없음** | 강사 예비 노트북(강사 계정) → 폴더만 USB로 가져감 | A + B 합친 경로 |

> 📌 제출 4칸(이름 · 주소 · 고친 규칙 한 줄 · 탭 수 변화) 중 **주소만 필수**. 로컬까지만 된 사람은 "주소 없음 + 규칙 한 줄"로 제출하면 수업 후 강사가 push를 안내합니다.
