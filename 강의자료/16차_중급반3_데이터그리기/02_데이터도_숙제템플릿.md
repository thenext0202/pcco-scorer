# 내 앱 데이터도 — 중급반 3강 숙제 (안내형)

> **숙제**: 화면에 보이지만 화면이 만들지 않은 것들 — 그것들이 **어느 표의 어느 열에 남는지**, 표끼리 **어떤 줄**로 이어지는지, **누가 읽고 쓰고 고치고 지울 수 있는지**를 종이에 그린다.
> 개발 환경 불필요 — 종이와 펜이면 충분. **구조도·화면도·데이터도 세 장이 「내 앱 설계 3종 세트」 — 다음 시즌은 이 세 장에서 시작합니다.**

---

## 1쪽 — 이 종이를 쓰는 법

**이름**: ____________　**날짜**: ____________　**내 앱 이름 (구조도·화면도와 같게)**: ____________

### 📖 작성 순서 — 이 다섯 단계면 됩니다

| 단계 | 할 일 | 어디에 |
|---|---|---|
| ① 남길 것 고르기 | 내 앱 화면에 보이는 **숫자·이름·글**을 쏟아내고, **남는 것 / 흐르는 것**으로 가른다 | 3쪽 위 |
| ② 표 이름 짓기 | 남는 것을 "한 종류의 사실"끼리 묶어 **표 2~3개**에 이름을 붙인다 | 3쪽 아래 |
| ③ 열 적기 | 표마다 **열 이름 + 종류(글자·숫자·시각·참/거짓·덩어리) + 필수 여부**를 적는다 | 4쪽 위 |
| ④ 줄 긋기 | **어느 표의 어느 열이 어느 표를 가리키나** — 표 사이에 줄을 긋고 "왜 갈랐나" 한 줄 | 4쪽 위 (같은 그림에) |
| ⑤ 문지기 표 | 표마다 **읽기·쓰기·고치기·지우기를 누가 하나** + 비밀 열쇠는 어디에 두나 | 4쪽 아래 |

> 💡 **막막하면 2쪽의 완성 예시부터 보세요.** 베끼는 게 아니라 형식을 빌리는 거예요.
> 💡 **화면도가 없어도 됩니다** — 지금 내 앱 화면을 떠올려 "거기 보이는 숫자·이름·글"만 적으면 ①이 시작됩니다. 아예 앱이 없으면 2쪽 소재(점심 메뉴 뽑기)로 시작하세요.
> 💡 열이 많은 순서가 아니라 **줄과 문지기를 빠뜨리지 않은 순서**로 좋은 데이터도입니다.

### 치트시트 — 창고 해부 4단 (오늘 배운 눈)

| 단 | 실명 | 스스로에게 던지는 질문 |
|---|---|---|
| 표 | 테이블 | 이 앱이 **남겨야 하는 사실**은 몇 종류인가? 한 줄(행)이 "사실 하나"인가? |
| 열 | 컬럼 | 각 사실에 **무엇을 적나**? 글자인가 숫자인가 시각인가? 꼭 있어야 하나? |
| 규칙 | 제약·관계 | **같은 값이 둘이면 안 되는 열**은? 다른 표를 **가리키는 열**은? |
| 열쇠 | 보안 | 이 표를 **누가 읽고·쓰고·고치고·지우나**? 내 앱이 쓰는 **비밀 열쇠**는 어디 두나? |

### 남는 것 vs 흐르는 것

| | 뜻 | 예 (채점기) |
|---|---|---|
| 남는 것 → 창고 | 앱을 껐다 켜도, 다른 사람이 봐도 있어야 하는 것 | 닉네임 · 점수 · 제출 시각 · 세션 코드 |
| 흐르는 것 → 창고 밖 | 그 순간만 필요한 것 | 채점 중 "빙글" · 등록 안 누른 결과 카드 · 쓰다 만 프롬프트(주머니) |

## 2쪽 — 완성 예시: 「점심 메뉴 뽑기」 (12차 구조도 · 14차 화면도와 같은 앱을 그대로 잇습니다)

**① 남길 것 고르기** — 화면도의 「보이는 데이터」 칸에서: 메뉴 이름 · 어제 뽑힌 메뉴 · 오늘 뽑은 시각 · 메뉴 종류(한식/중식…)
- 남는 것: 메뉴 이름 · 메뉴 종류 · 뽑은 시각 · 뽑힌 메뉴 · 먹었나
- 흐르는 것: "뽑는 중…" 연출 · 화면에 잠깐 뜨는 "왜 이 메뉴인지" 문장 (매번 계산)

**② 표 이름 짓기** — 사실이 두 종류: "이런 메뉴가 있다" / "언제 무엇을 뽑았다"

| 표 | 한 종류의 사실 | 한 줄 = |
|---|---|---|
| 메뉴 표 | 등록해 둔 메뉴 | "김치찌개(한식)를 3월 2일에 등록했다" |
| 뽑기기록 표 | 뽑은 사건 | "3월 9일 12:10에 김치찌개가 뽑혔고, 먹었다" |

**③ 열 적기 + ④ 줄 긋기**:

```
┌ 메뉴 표 ───────────────────────┐        ┌ 뽑기기록 표 ─────────────────────────┐
│ 번호      덩어리 번호  필수·자동 │◀──┐   │ 번호       덩어리 번호   필수·자동      │
│ 이름      글자 30자   필수·유일 │   └───│ 메뉴번호   덩어리 번호   필수 → 메뉴.번호│
│ 종류      글자        허용목록  │        │ 뽑은 시각  시각          안 적으면 지금  │
│ 등록 시각 시각        안 적으면 지금│     │ 먹었나     참/거짓       기본 "아니오"   │
└────────────────────────────────┘        └────────────────────────────────────────┘
```

**줄**: 뽑기기록.메뉴번호 → 메뉴.번호 (메뉴를 지우면 그 메뉴의 기록도 같이 — 삭제 연쇄)
**왜 갈랐나**: 김치찌개를 열 번 뽑으면 "김치찌개·한식"이 열 줄에 반복된다 → 이름을 고치면 열 군데. 메뉴는 메뉴 표에 한 번만, 기록은 번호로 가리킨다.

**⑤ 문지기 표**:

| 표 | 읽기 | 쓰기 | 고치기 | 지우기 |
|---|---|---|---|---|
| 메뉴 표 | 모두 | 나만 | 나만 | 나만 |
| 뽑기기록 표 | 모두 | 모두 | **X** (뽑힌 건 뽑힌 것) | **X** |

**비밀 열쇠**: 없음 (외부 AI·결제 안 씀) → 공개 열쇠만, 문지기가 지킨다. *(만약 "왜 이 메뉴인지"를 AI가 쓰게 한다면 → 그 열쇠는 서버 서랍에)*

**★ 보너스 — 흐르는 것 1개**: "뽑는 중…" 1초 연출 — 창고에 안 남긴다

> ✅ 합격 기준과 대조: 표 2개 이상 + 열 3개 이상? ✓ (2표, 4열·4열) / 줄 1개 + 왜 갈랐나? ✓ / 문지기 표 고치기·지우기 칸 채움? ✓ (X도 답)
