# 프롬프트 역설계 채점 루브릭 (10차 강의)

> 플랫폼 `reverse` 채점 모드의 기준 문서.
> 상세 원본: `강의자료/10차_프롬프트역설계_IG아카이버/04_채점기준표.md` (강사용, 수업 전 비공개)
> 시스템 프롬프트: `src/lib/reverseScoringPrompt.ts`

## 개요

수강생이 완성 프로그램 **IG 아카이버**(인스타그램 캐러셀 이미지 아카이빙 데스크톱 앱)를
**exe만 사용해 보고**(소스 비공개) 작성한 "한 방 프롬프트"를 채점한다.

평가 기준은 단 하나: **"이 프롬프트만 받은 AI가, 그 프로그램을 그대로 만들 수 있는가?"**

목적은 학습 수준 진단(초급반/중급반 분반). 리더보드 점수는 참고 지표이며,
최종 분반은 강사의 원문 검토 + 수강생 본인 희망으로 결정한다.

## 구조 — 4축 × 25점 = 100점 (★ 다른 모드와 다름)

기존 4개 모드(prompt/instruction/image/vibe)는 5요소 × 20점이지만,
**역설계 모드는 4축 × 25점**이다. elements 키: `observe` / `spec` / `edge` / `structure`.
가점·감점 없음 (`bonuses: []`, `penalties: []` 고정) — 총점 = 4축 합.

| 축 | 키 | 내용 | 배점 |
| --- | --- | --- | --- |
| A 기능 관찰 | observe | 기능 지도 15항목 체크 — 층1(각 1점)·층2(각 2점)·층3(각 2점) | 25 |
| B 명세 구체성 | spec | 저장 구조·파일명 규칙·데이터 파일·GUI·산출물 정의 (5부문 × 5점) | 25 |
| C 예외·제약 인식 | edge | 요청 한도·실패 처리·중복/재실행·영상 처리·중단/안전 (5부문 × 5점) | 25 |
| D 프롬프트 구조 | structure | 역할·목적 / 맥락 / 구획화 / 제약 명시 / 완료 기준 (5부문 × 5점) | 25 |

채점 원칙: 행동 명세만 채점하고 구현 기술(언어·라이브러리)은 무가점·무감점.
표현이 달라도 의미가 같으면 인정. 층3의 13번(의도적 딜레이 = 레이트리밋 회피)이
중급 판단의 최중량 신호.

## ★ 답 유출 금지 (이 모드만의 핵심 제약)

수업 중 재제출로 정답을 캐내는 것을 막기 위해, 채점 결과의 **모든 필드**에서
수강생이 스스로 적지 않은 **구체 기능명·파일명·수치를 노출하지 않는다.**
피드백은 범주 수준까지만 ("결과물이 남는 방식에 대한 관찰이 없다" 수준).

- `improved_example`은 다른 모드와 달리 **모범답안이 아니라 "다시 관찰하러 가기"
  질문 가이드**다 (4~6개의 셀프 확인 행동 지시). UI(ReverseScoreResult)에도
  복사·claude.ai 버튼 없이 안내 카드로만 렌더링한다.
- API 라우트에서 bonuses/penalties를 강제로 빈 배열로 덮어쓴다.

## 등급·분반 참고 구간

등급: S(95+) / A(85+) / B(70+) / C(50+) / D(30+) / F(0~29) — 다른 모드와 동일.

분반 참고 (강사 전용 — 결과 화면에 노출하지 않음):
~49 초급 권장 / 50~74 중급 권장 / 75+ 중급(심화 후보).
최종 분반 = 수강생 희망 + 강사 원문 검토. 경계선(45~55)은 원문 재검토.

## 입력 제한

한 방 프롬프트는 프로그램 전체 명세라서 길다: 최소 50자, **최대 4,000자**
(다른 모드는 1,000~1,500자).
